# R0.73L finite adiabatic diagnostic

This package evolves the selected branch of finite Fourier compressions for
the complete slow interval \(0\le d\le1/450\).  It records action-normalized
gain, instantaneous complementary leakage, backward-action residuals computed
only from the forward orbit, epsilon scaling, cutoff agreement, progress, and
resource use.

Run the exact command in `command.txt` from the repository root.  The package
is diagnostic only: neither cutoff agreement nor an observed \(O(\varepsilon)\)
leakage law proves the continuum theorem.
