00 / Certified structural no-go

仅依赖方向的有符号环带平均不能一致压低拉伸核

固定一个不接触原点的环带 \(A\)，冻结 \((x,t)\)，并令

\[ K_{x,t}(z)= \frac{D(\widehat z,\xi(x+z,t),\xi(x,t))}{|z|^3}. \]

对所有非负单位质量权重，严格恒等式是

\[ \boxed{ \sup_{\substack{g\ge0\\ \int_Ag=1}} \left|\int_AK_{x,t}(z)g(z)\,dz\right| =\|K_{x,t}\|_{L^\infty(A)}.} \]

因此，角核即使有强烈的正负相消，只要模长权重能够偏向一个符号瓣，最坏情形仍恢复核的完整上确界。任何真正有用的条件都必须控制实际配对 \((\xi,|\omega|)\)，或利用 \(\nabla\cdot(|\omega|\xi)=0\) 与动力学施加的耦合。

01 / Periodic signed kernel

周期局部奇性正是 Constantin 的方向几何因子

在 \(|\omega(x)|>0\) 的位置，记 \(\xi=\omega/|\omega|\)、\(S=(\nabla u+(\nabla u)^T)/2\)、 \(\alpha=\xi\cdot S\xi\)。若平均为零的周期 Green 函数满足 \(-\Delta G=\delta_0-(2\pi)^{-3}\)，则

\[ \boxed{ \alpha(x)=\xi_i(x)\xi_\ell(x)\varepsilon_{ijk} \operatorname{p.v.}\!\int_{\mathbb T^3} \partial_{\ell j}G(z)\,\omega_k(x+z)\,dz.} \]

在小于注入半径的球内，\(G(z)=(4\pi|z|)^{-1}+H(z)\)，其中 \(H\) 光滑。取局部截断 \(\chi\) 后，

\[ \alpha(x)=\frac{3}{4\pi}\operatorname{p.v.}\!\int \chi(z)D(\widehat z,\xi(x+z),\xi(x)) \frac{|\omega(x+z)|}{|z|^3}\,dz +\mathcal R_\chi\omega(x), \]

其中

\[ \boxed{D(e_1,e_2,e_3)= (e_1\cdot e_3)\bigl(e_1\cdot(e_2\times e_3)\bigr),} \]

且光滑余项满足 \(|\mathcal R_\chi\omega(x)|\le C_\chi\|\omega\|_{L^1}\)。这一步是已知几何拉伸公式在周期域的局部写法，不主张新颖性。

02 / Positive-weight robustness

证明只需要 \(L^1_+\) 与 \(L^\infty\) 的对偶端点

对任意 \(K\in L^\infty(A)\) 和 \(g\ge0\)、 \(\int_Ag=1\)，

\[ \left|\int_AKg\right| \le\int_A|K|g\le\|K\|_\infty. \]

反方向上，在 \(K\) 接近其正上确界或负下确界的正测度集合上取归一化示性函数，就能任意逼近 \(\|K\|_\infty\)。这证明了上面的等式。

严格边界。 这个论证没有说明每个选择权重都能实现为光滑散度为零的涡量，更没有说明它能出现在 Navier–Stokes 解上。它排除的是一种证明架构：只读取方向核，同时把模长当作任意非负权重，却仍希望从符号振荡得到一致增益。
03 / Four-lobe model

均匀平均为零，不等于对实际模长稳健

固定 \(\xi(x)=e_3\)、 \(\xi(x+z)=(\sin\varphi,0,\cos\varphi)\)。单位球面上的核为

\[ D=-\sin\varphi\,\widehat z_2\widehat z_3, \qquad \|D\|_\infty=\frac{|\sin\varphi|}{2}, \qquad \frac1{4\pi}\int_{\mathbb S^2}|D|\,d\sigma =\frac{2|\sin\varphi|}{3\pi}. \]

均匀角平均恰好为零。可是对 \(g_\eta=1+\eta\operatorname{sgn}D\)、\(0\le\eta<1\)，

\[ \boxed{ \frac{\int_{\mathbb S^2}Dg_\eta\,d\sigma} {\int_{\mathbb S^2}g_\eta\,d\sigma} =\eta\frac{2|\sin\varphi|}{3\pi}.} \]

任意正偏置都会把精确相消变成正的有符号平均。正式附图把四个符号瓣与这条线性响应放在同一张图中。

04 / Literature boundary

取绝对值会回到经典方向相干；环带与交换子已有近期预印本

经典估计 \(|D(e_1,e_2,e_3)|\le|\sin\angle(e_2,e_3)|\) 导向 Constantin–Fefferman 的方向相干机制。后续工作把空间正则度降到 \(1/2\)-Hölder，并把条件局部化到任意小的抛物柱。因此，只给方向场加逐点模连续条件会重述已知正则性准则。

2026 年还有两篇与这里很接近的 arXiv 预印本：一篇研究对数加权 BMO 交换子，另一篇研究滤波拉伸、环带重分配与条件 Carleson 闭合。本页没有独立验证它们的全部证明，也不把它们当作已审稿定理。今后若再次进入交换子或环带打包，必须逐条比较。

05 / Value for the main problem

结果没有给出正则性，但把缺失信息定位得更准确

R0.69F 表明无符号标量预解只能恢复经典尺度；R0.69G 进一步表明，单独恢复方向符号仍不够。需要保留的是方向和模长怎样由散度约束、输运、扩散与压力共同耦合。

这缩小了下一步：不再尝试仅依赖方向的环带平均，而是检查应变方程中的压力 Hessian 是否对主拉伸方向提供可量化的非局部补偿。

本页没有证明奇性存在或不存在，也没有解决三维 Navier–Stokes 千禧年问题。
