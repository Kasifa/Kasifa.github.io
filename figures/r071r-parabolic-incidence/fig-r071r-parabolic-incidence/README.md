# fig-r071r-parabolic-incidence

Paper-ready four-panel figure for R0.71R.  The package contains the exact and
independent release certificates, tabular plotting data, producer and
independent validators, PDF/SVG/600 dpi PNG outputs, and color/grayscale QA
previews.  Run the commands in `command.txt` from the repository root.

This is an exact-audit and deterministic presentation-sampling package.  It
contains no DNS or PDE time stepping.  The only NSE family displayed is an
exact initial Fourier jet and its first-jet scaling coefficient.
