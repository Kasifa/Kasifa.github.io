01 / Background class

把“扣除背景”写成一个可证伪的函数类

对 \(C\in\{B_U,B_V,H_U,H_V\}\)，我检查

\[C(x)=P_d(x)+M(x),\qquad M(x)=\int_{[0,\infty)}\frac{d\mu(t)}{1-xt},\qquad \mu\ge0,\qquad \deg P_d\le d.\]

\(P_d\) 可以有任意实系数；没有符号、大小或插值约束。若 \(M(x)=\sum_{n\ge0}m_nx^n\)，则多项式只能改变前 \(d+1\) 项：

\[m_n=c_n\qquad(n>d),\qquad C(x)=\sum_{n\ge0}c_nx^n.\]

这条尾部不变性使整类背景能被一个位于 \(d\) 之后的精确反例同时排除。

02 / Tail Gram condition

非负测度要求每个移位尾块半正定

取整数 \(s>d\) 和有限单项式指标集 \(I=\{i_0,\ldots,i_{r-1}\}\)。若正测度表示存在，则

\[G^{(s,I)}_{\alpha\beta}=m_{s+i_\alpha+i_\beta}=\int t^s t^{i_\alpha}t^{i_\beta}\,d\mu(t).\]

因为 \(t^s\ge0\)，对任意实向量 \(a\) 都有

\[a^\mathsf T G^{(s,I)}a=\int t^s\!\left(\sum_\alpha a_\alpha t^{i_\alpha}\right)^2d\mu(t)\ge0.\]

所以 \(G^{(s,I)}\) 必须半正定。另一方面，\(s>d\) 使矩阵的每个元素都等于 \(C\) 的原始精确系数。只要找到一个负行列式，就能一次排除该次数范围内的全部背景系数。

04 / Proof structure

证明只需要尾部不变性和一个负 Gram 行列式

以 \(B_U\) 为例。若 \(d\le43\)，取 \(s=44\) 和 \(I=\{0,1,2\}\)。必要矩阵是

\[G_U=\begin{pmatrix}b^U_{44}&b^U_{45}&b^U_{46}\\b^U_{45}&b^U_{46}&b^U_{47}\\b^U_{46}&b^U_{47}&b^U_{48}\end{pmatrix},\qquad \det G_U<0.\]

所有下标都大于 \(d\)，所以任何 \(P_d\) 都不能改变这个矩阵。非负测度却要求它半正定，矛盾。\(B_V\) 使用 \(s=45\) 的同型三阶矩阵；\(H_U\) 直接由负系数 \(h^U_{47}\) 排除；\(H_V\) 使用

\[\det\begin{pmatrix}h^V_{46}&h^V_{47}\\h^V_{47}&h^V_{48}\end{pmatrix}=h^V_{46}h^V_{48}-(h^V_{47})^2<0.\]

四个论证都对背景系数作全称量化。这里没有从有限样本外推行列式符号；一个已经确定的有限负主子式本身就足以否定整类表示。

05 / Finite window

“最大阈值”只表示当前系数窗内没有更晚的负见证

审计枚举了尾起点 \(40\le s\le49\) 内能由现有系数形成的全部相关主子式。指标集统一包含零；任何不包含零的指标集都可整体平移为更晚的尾起点。四个序列共检查 216 个精确有理行列式，其中 67 个为负。

在现有窗口内，负见证最晚出现在 \(s=44,45,47,46\)。更晚的已测试主子式没有负值，但这不证明 \(B_U\) 的 44 次背景可行，也不证明其他序列的下一次数可行。若以后得到更多精确系数，仍可能出现更晚的负尾块。

不能倒置有限诊断。“没有在当前窗口找到反例”不等于“存在正测度”。存在性需要全部矩条件或另一条完备定理。

07 / Research value

这个结果关闭了“删掉有限 Taylor 头部即可修复”的解释

R0.33 只否定直接正测度表示，因此一个自然补救是先减去解析背景。R0.34 说明：如果背景只是有限次多项式，那么即使给它四十多个完全自由的实系数，也无法修复四个候选序列的矩正性。这个结论排除的是整个有限维背景类，不是某次拟合失败。

它对当前边缘模型有明确的方法价值：继续增加有限 Taylor 背景参数没有理论收益。下一项工作应给无限背景加入可检验的解析约束，或者直接构造带显式余项界的延拓链。

它对三维 Navier–Stokes 千禧年问题的直接价值仍然很小。这里研究的是一个边缘形式级数的表示类别；尚未建立从该级数的解析延拓到完整三维 PDE 临界范数、弱解唯一性或有限时奇性的控制桥梁。

当前不能声称的内容。不能声称全部 Padé 路线已失败，不能声称约 \(-0.7495\) 的候选是真实奇点或伪影，不能声称无限解析背景不存在，也不能从这四个尾部行列式推出三维 Navier–Stokes 正则性或爆破解。
08 / R0.35

下一步转向有范数控制的解析延拓

  1. 把固定荷抽取与荷阶梯写成加权序列空间上的显式算子系统；
  2. 选择能控制卷积、荷平移和参数导数的权重，并证明算子在该空间内闭合；
  3. 建立一个可检查的局部延拓引理：给定圆盘内系数界和边界余量，认证相邻圆盘；
  4. 先用精确有理或区间算法验证短链，再判断是否有可能沿负实轴接近 R0.32 候选；
  5. 在延拓链真正覆盖候选位置之前，不作原函数奇点判断。

R0.35 的最低交付不是新的 Padé 图，而是一个有明确空间、范数、域和余项条件的延拓命题，以及它能否被现有系数证书触发的判断。
