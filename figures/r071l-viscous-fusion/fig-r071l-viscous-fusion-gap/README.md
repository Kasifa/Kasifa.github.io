# R0.71L journal figure package

This package archives the exact fixed-cell cancellation profile, the
standalone deterministic witness diagnostic, the scale ledger, and the
Leray-payment implication boundary used in R0.71L.

The evidence classes are panel-specific. Panel A is exact algebra. Panel B is
a deterministic quadrature diagnostic and is not a continuous sign
certificate. Panel C is mixed evidence: the local heat/support $K^{-4}$
entry records an earlier analytic upper-scale bound, whereas the nonzero
fused-tangent $K^{-2}$ coefficient is a fixed-witness deterministic
diagnostic, not an interval sign certificate. The checker supplies that
leading coefficient; the accompanying $O_\nu(K^{-3})$ finite-$K$ remainder
comes from earlier analytic finite-$K$ theory and is not proved by the
checker. Panel D is an exact implication ledger. The package contains PDF,
SVG, and 600 dpi PNG exports, source data, two validation paths, visual-QA
previews, provenance, and SHA-256 hashes.
