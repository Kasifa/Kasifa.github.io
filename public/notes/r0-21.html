01 / Viscous target coefficients

热算子第一次进入目标模的严格展开

令 \(\delta=4^{-n}\) 且 \(\tau=\delta^{-2}t\)。目标 Fourier 系数写成

\[ P_{\mathrm{tar}}u(\tau) =(-i)^5 A_5\tau^5 \bigl(1+r_6\tau+r_7\tau^2\bigr) +\mathcal R_{\geq8}(\tau). \]

在 R0.20 第一个根的半径 \(10^{-6}\) 有理盒上，外向区间计算给出

\[ r_6\in[-2.611276916335079,-2.6112696484122124], \] \[ r_7\in[-2.8144704386643693,-2.814414371216345]. \]

六阶项只来自一次热插入。七阶项由两次热插入与八叶纯非线性树共同组成； 其相对五阶的三个已认证分量约为 \(+3.58634\)、\(-5.86797\) 和 \(-0.53281\)。 所有负 Laurent 幂精确抵消，所得向量严格落在目标极化直线上。

不能从前三项直接判定正时间符号。 只有在 \(\mathcal R_{\geq8}\) 的严格上界小于前三项给出的目标下界之后， 这个有限阶展开才能升级为完整粘性解的非零目标传递结论。

精确 signed multiplicity 枚举得到目标频率的次数：

叶数12345678
目标次数000003014

所以目标模的时间零至四阶即使加入热项仍为零；第五阶等于 R0.20 的纯非线性项； 六阶没有七叶纯非线性贡献；七阶才第一次出现新的八叶纯非线性树。

03 / Transformed cube support

八个输入频率是一个线性变换立方体的顶点

每个频率都可唯一写成

\[ K_\delta(c,\beta)=\delta^{-1}c(1,1,1)+\beta, \qquad \beta\cdot(1,1,1)=0. \]

在有理坐标 \(G(c,\beta)=(6c,3\beta_1,3\beta_2)\) 中，八个 signed 输入恰好是 \(\{\varepsilon_1a+\varepsilon_2b+\varepsilon_3c\}\)，其中每个 \(\varepsilon_j\in\{-1,1\}\)，且

\[ a=(3/2,0,0),\quad b=(0,0,3/2),\quad c=(-1/2,1,-1/2), \qquad \det(a,b,c)=-9/4. \]

因此恰含 \(L\) 个输入叶子的支持计数为

\[ \#S_L=\begin{cases} (L+1)^3,&L\text{ 为奇数},\\ (L+1)^3-1,&L\text{ 为偶数}. \end{cases} \]

这是任意叶数的代数证明，不是只到有限阶的拟合。机器运行另外检查到 13 叶， 共核对 11,024 个生成标签；每个主频向量都平行于对角线，每个偏移都垂直于对角线。

04 / Modewise cancellation

不可压缩性消去表面上的 \(4^n\) 导数

模式级算子引理。

若 \(u_1\) 在 \(K_\delta(c_1,\beta_1)\) 上无散且 \(c_1\ne0\)，则

\[ K_\delta(c_2,\beta_2)\cdot u_1 =\left(\beta_2-\frac{c_2}{c_1}\beta_1\right)\cdot u_1. \]

定义纵向半范数

\[ L_\delta(u)=\delta^{-1}|(1,1,1)\cdot u|. \]

则对所有电荷，包括 \(c_1=0\)，都有

\[ |K_2\cdot u_1| \le |\beta_2|\,|u_1|+|c_2|L_\delta(u_1). \]

Leray 投影后的欧氏分量和纵向分量也满足不含负 \(\delta\) 幂的模式级估计。 热乘子同时满足精确恒等式 \(\delta^2|K_\delta|^2=3c^2+\delta^2|\beta|^2\)。 因而先前最直接的 \(4^n\) 壳层障碍并未出现。

05 / Floating-point diagnostic

十二阶数值结果只用于选择下一条证明路线

独立的 complex128 递推计算了壳层 \(n=3,4,5\) 的完整粘性 Taylor 系数至十二阶。 三个运行在十二阶都得到 4,772 个非零 Fourier 模；其 Fourier \(\ell^1\) 根指标分别为 3.08898、3.10146 和 3.10229。

这些数值随壳层趋于稳定，支持“存在壳层一致估计”的工作假设。 但它们没有外向舍入，也没有覆盖所有更高时间阶，因此不参与严格符号结论。

06 / Meaning

进展在于排除一个障碍，而不是解决原问题

已经得到

  • R0.20 最优根盒上的前两个粘性修正有严格区间，不再只是中心点浮点数。
  • 频率支持由指数式树枚举压缩为精确的立方格点几何。
  • charge-zero 输出不会自动重新引入 \(4^n\) 损失。

仍未得到

  • 带解析权的无限卷积映射是否只损失一个解析半径导数。
  • 十二阶近似解残差的外向区间上界和完整 Taylor 尾。
  • 某个 \(\tau_0>0\) 上完整解的严格目标下界。
  • 临界范数增长、跨壳迭代或任何 Clay 问题结论。
07 / Next gate

下一步先判定解析半径损失的阶数

  1. 用立方坐标定义最小叶半径和指数解析权。
  2. 对 \(|u|+L_\delta(u)\) 建立完整卷积不等式，并追踪最优常数。
  3. 若只有一阶半径损失，构造时间 Taylor 主级数；若出现二阶损失，检查热半群或更细的结构性抵消。
  4. 估计闭合后，把十二阶近似解、区间残差和标量控制方程接到同一证书链。

这一阶段主要是精确代数和函数空间估计，不需要大规模 GPU。 大量参数盒或十二阶区间残差扫描开始前，再根据基准测试决定是否使用 DGX。

08 / Reproduction

脚本、证书与复现命令

R0.21 机器文件位于 research/certificates/r021。 三个 JSON 文件均有 SHA-256 清单；每次精确运行在输出中记录源提交和工作树状态。

PYTHONPATH=research python3.12 research/viscous_target_taylor_audit.py --check --pretty --progress
PYTHONPATH=research python3.12 research/cone_frequency_cancellation_audit.py --check --pretty --progress --maximum-leaves 13
cd research/certificates/r021 && shasum -a 256 -c SHA256SUMS

精确粘性系数的干净源提交为 692c8f1…；频率几何证书的干净源提交为 3440e29…。归档结果使用 Python 3.12.13；前者运行约 24 秒，后者约 0.61 秒。
