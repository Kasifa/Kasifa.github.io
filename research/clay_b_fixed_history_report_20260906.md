# 完整时间历史检查：多得到了一条尾估计，还没有刚性

2026-09-06。**BOUNDED HISTORY SCREEN COMPLETE / CONDITIONAL RESULTS / G OPEN / NOT CLAY。**

我完成了上次留下的两个检查：完整 mild 历史，以及 record 峰值
的倍增时间。真正多得到的是一条由原解能量支付的远过去尾估计。
它只在随峰值增长的时间窗口之外趋零，不能排除常向量古老极限。
倍增时间的检查也没有给出一般初值所需的新上界。

## 1. 能量支付的范围

对同一固定初值的首次候选奇点，记峰值为 \(M_k\)，归一化完整
历史为 \([-b_k,0]\)，其中 \(b_k=M_k^2t_k\)。BI 使用完整
周期 Oseen 核、Leray 投影和规范压力，写出

\[
 v_k(0)=H_k+N_{k,\mathrm{old}}^S+N_{k,\mathrm{recent}}^S.
\]

固定初值给 \(\|H_k\|_\infty\to0\)。基本能量还给

\[
 \|N_{k,\mathrm{old}}^S\|_\infty
 \le CE_0\left(M_k/S+t_k/M_k\right).
\]

所以对 \(S_k=M_k^{1+\eta}\)、\(0<\eta<1\)，有
\(N_{k,\mathrm{old}}^{S_k}\to0\)。这是一条真实的 NS 估计。
但 \(S_k\to\infty\)，没有把终点的非线性来源压缩到固定窗口。

若另假设局部极限是单位常向量 \(c\)，每个固定 \(S\) 内的
近期非线性项反而趋零，因此 \(N_{k,\mathrm{old}}^S\to c\)。
这与增长窗口的尾小性不矛盾：两者之间的时间段可保留有符号贡献。
原时间中的该段长度趋零，归一化时间中的长度却趋于无穷。

这里的“可保留”是条件公式要求的必要来源，不是构造了真实奇点。
不能先在固定窗口取极限，再未经证明把它改成增长窗口。

## 2. 倍增速度没有提供缺失上界

BJ 令 \(M_j=2^jM_0\)、\(t_j\) 为首次达到时刻，
\(D_j=M_j^2(t_j-t_{j-1})\)。已付信息是

\[
 D_j\ge4c_*,\qquad \sum_j4^{-j}D_j<\infty.
\]

第一个来自统一局部 mild 寿命，第二个来自有限总时间。两者都不
给出 \(D_j\) 的上界。显式标量时间族 \(D_j=d_*+j^2\)
满足这两条账本，却无有界子列；它不是 NS 或能量模型反例。

如果另行证明某条子列 \(D_j\le C\)，就能在古老极限中保留
一个过去时刻的速度上界 \(1/2\)，而终点模长为 1，从而排常量。
速度 Type I 假设足以给这个上界，但本节没有从任意初值推出它。
即使排除了常量，一般三维非恒定古老解的刚性仍未解决。

## 3. 一个不能直接使用的文献出口

Albritton–Barker 的 Theorem 1.2 针对同一个全空间 mild 古老解，
要求它在一列趋于负无穷的时刻具有统一全空间 \(L^3\) 界。
在这些条件下解为零。准确版本与阅读边界见配套原文记录。

固定 \(u_0\) 确实给出

\[
 \|v_k(-b_k)\|_{L^3(\mathbb T_{M_k}^3)}=\|u_0\|_{L^3(\mathbb T^3)}.
\]

但这是不同 \(v_k\) 在不同、逃向负无穷的左端时刻的胞范数。
周期提升自身也不是全空间 \(L^3\) 函数，除非为零。
局部紧性没有将这条数据转换成极限 \(v\) 在固定时刻的全空间
界，更没有得到原定理要求的整列时刻。正文没有引入这样的假设。
