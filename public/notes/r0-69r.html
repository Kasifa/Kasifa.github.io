研究笔记 R0.69R · 非局部涡量差分的无增益定理

差分消掉了近场奇性，
但远场把指数精确送回原点

我没有先把涡量模长与方向拆开，而是把 \(\omega(x)\times\omega(x+z)\) 改写为精确涡量差分，再把完整空间分成近场与远场。近场核由临界的 \(ds/s\) 变成可积的 \(ds\)，这个改善是真实的；然而远场只能由 enstrophy 控制。对分裂半径做精确优化后，结果唯一回到 \(A^{3/2}B^{3/2}\)，Young 吸收仍产生 \(A^6\)。

00 / Main result

非局部差分改善核，却没有改善最终范数指数

令 \(A=\|\omega\|_{L^2(\mathbb R^3)}\)、\(B=\|\nabla\omega\|_{L^2(\mathbb R^3)}\)。对任意 \(r>0\)，完整的绝对拉伸生产满足

\[ \boxed{\int_{\mathbb R^3}|\omega|^2|\xi\cdot S\xi|\,dx \le C_{\rm n}rA^{1/2}B^{5/2} +C_{\rm f}r^{-3/2}A^3.} \]

精确最小化右端得到

\[ \boxed{r_*=\left(\frac{3C_{\rm f}}{2C_{\rm n}}\right)^{2/5}\frac AB, \qquad \int|\omega|^2|\xi\cdot S\xi| \le C_*A^{3/2}B^{3/2}.} \]
严格边界。 这关闭的是“近场取差分、远场只用能量、随后逐项取绝对值”的范数路线。它没有否定不同尺度之间的有符号抵消，也没有证明全局正则性、有限时爆破或千禧年问题。
01 / Signed stretching kernel

几何表示把拉伸写成跨空间点的幅值—方向耦合

在 \(\rho=|\omega|>0\) 上写 \(\xi=\omega/\rho\)、\(\alpha=\xi\cdot S\xi\)。全空间几何表示具有形式

\[ \alpha(x)=\frac{3}{4\pi}\operatorname{p.v.}\!\int_{\mathbb R^3} D(\widehat z,\xi(x+z),\xi(x)) \frac{\rho(x+z)}{|z|^3}\,dz, \]

其中 \(D(e_1,e_2,e_3)=(e_1\cdot e_3)[e_1\cdot(e_2\times e_3)]\)，且 \(|D|\le|e_2\times e_3|\)。和只控制 \(|\nabla\xi|\) 的路线不同，这个表示在同一个积分核里保留了邻点涡量的模长与方向。

02 / Exact difference

交叉积自动减去常量部分，无需预设方向连续模

关键恒等式不是估计，而是精确消去：

\[ \boxed{\omega(x)\times\omega(x+z) =\omega(x)\times\bigl(\omega(x+z)-\omega(x)\bigr).} \]

于是 \(\rho(x)^2\rho(x+z)|\xi(x+z)\times\xi(x)|\) 可由 \(\rho(x)^2|\omega(x+z)-\omega(x)|\) 控制。这个步骤把方向差与模长差重新合并，避免了 R0.69Q 中 \(\rho=0\) 附近的 \(\nabla\log\rho\) 漂移。

03 / Near field

差分真实移除一个近场奇性阶，但付出一阶导数

对 \(|z|\le r\)，微积分基本定理给出

\[ |\omega(x+z)-\omega(x)| \le |z|\int_0^1|\nabla\omega(x+\theta z)|\,d\theta. \]

结合中心 Hardy–Littlewood 极大算子的径向估计

\[ \int_{|z|\le r}\frac{|\omega(x+z)-\omega(x)|}{|z|^3}\,dz \le4\pi r\,M(|\nabla\omega|)(x), \]

再用 \(L^2\) 极大算子界、Hölder 与三维 Gagliardo–Nirenberg 不等式，得到

\[ \boxed{|\mathcal V_{\rm near}| \le Cr\|\omega\|_4^2\|\nabla\omega\|_2 \le C_{\rm n}rA^{1/2}B^{5/2}.} \]

原先临界的径向测度 \(ds/s\) 确实变成 \(ds\)；损失发生在极大函数中的一阶导数，不是差分无效。

04 / Far field

有限 enstrophy 控制远场，同时恢复丢失的尺度

截断核的 \(L^2\) 范数可以精确计算：

\[ \left\|\mathbf1_{\{|z|>r\}}|z|^{-3}\right\|_2^2 =4\pi\int_r^\infty s^{-4}\,ds=\frac{4\pi}{3r^3}. \]

Young 卷积不等式因此给出远场势的 \(L^\infty\) 控制，乘上 \(\rho^2\) 再积分即得

\[ \boxed{|\mathcal V_{\rm far}|\le C_{\rm f}r^{-3/2}A^3.} \]

这一步只使用有限 enstrophy，也正是在这里，近场差分获得的尺度改善被远场重新收回。

05 / Exact radius optimization

最优半径就是 enstrophy 长度，没有剩余小参数

对 \(F(r)=Xr+Yr^{-3/2}\)，唯一临界点和最小值为

\[ \boxed{r_*=\left(\frac{3Y}{2X}\right)^{2/5},\qquad \min_{r>0}F(r)=\frac53\left(\frac32\right)^{2/5}X^{3/5}Y^{2/5}.} \]

代入 \(X=C_{\rm n}A^{1/2}B^{5/2}\)、\(Y=C_{\rm f}A^3\)，可见 \(r_*\) 正比于 \(A/B\)，而 \(X^{3/5}Y^{2/5}\) 精确等于常数乘 \(A^{3/2}B^{3/2}\)。所以结果不是任意选取分裂半径造成的松弛。

06 / Scaling uniqueness

只使用 \(A\) 与 \(B\) 时，两个指数被缩放完全锁死

若希望有齐次单项式界 \(|\mathcal V|\le CA^pB^q\)，振幅缩放 \(u\mapsto au\) 要求 \(p+q=3\)。Navier–Stokes 空间缩放 \(u_\lambda(x)=\lambda u(\lambda x)\) 下，\(\mathcal V\mapsto\lambda^3\mathcal V\)、\(A\mapsto\lambda^{1/2}A\)、\(B\mapsto\lambda^{3/2}B\)，所以 \(p+3q=6\)。

\[ \boxed{p+q=3,\qquad p+3q=6 \quad\Longrightarrow\quad p=q=\frac32.} \]

这意味着，只要最终仍把全部信息压缩成 \(A\) 与 \(B\) 两个全局范数，重新排列 Hölder 或插值步骤不能改变最终指数。

07 / Young endpoint

黏性吸收后的最优余项仍然是六次 enstrophy 范数

令 \(D=B^2\)。优化后的非线性为 \(C_*A^{3/2}D^{3/4}\)。对任意 \(\varepsilon>0\)，精确 Young 优化给出

\[ \boxed{C_*A^{3/2}D^{3/4} \le\varepsilon D+ \frac{27C_*^4}{256\varepsilon^3}A^6.} \]

于是 enstrophy 预算仍是 \(\frac d{dt}A^2+\nu B^2\lesssim\nu^{-3}A^6\) 的经典局部微分控制。它不能为任意大数据提供统一全局上界。

08 / Value for the main problem

这是严格的无增益定理，不构成正则性结论

正面结果是：不假设方向 Hölder 连续性，精确涡量差分就能把近场核降一个奇性阶。负面结果同样严格：只要远场退回 \(L^2\) enstrophy、并在每个尺度先取绝对值，最优尺度必定回到 \(A/B\)，指数必定回到 \(3/2,3/2\)，时间余项必定回到六次。

价值判断。 这个版本没有产生新的条件正则性判据，因此尚不足以单独成为高水平正面定理。它的研究价值是关闭一条自然且技术上完整的路线，并证明下一步必须保留第三种信息：有符号跨尺度抵消、临界 Besov/Morrey 量，或模长集中与方向几何之间的动力学约束。

10 / Next stage

R0.69S 将在取绝对值之前检查有符号尺度局部通量

下一步用环带分割 \(\sum_j\psi_j(z)=1\) 保留几何核的符号，定义尺度贡献

\[ \mathcal F_j(t)=\int\rho(x)^2\int \psi_j(z)D(\widehat z,\xi(x+z),\xi(x)) \frac{\rho(x+z)}{|z|^3}\,dz\,dx. \]

核心问题不是逐个控制 \(|\mathcal F_j|\)，而是研究相邻尺度部分和是否存在可求和的有符号亏损，并把截断误差明确保留为通量。验收标准是得到尺度临界、时间可积且不等价于已知 Serrin/方向相干假设的控制；如果绝对值不可避免地再次出现，就用本版本的缩放审计关闭该子分支。

12 / Sources and boundary

经典几何表示与本次路线审计分开陈述

涡量方向的几何耗散机制与奇异积分表示始于 Constantin–Fefferman；Hardy–Littlewood 极大算子、Gagliardo–Nirenberg 插值和近远场分割是标准调和分析工具。本版本不把这些经典工具声明为新结果。

主要来源：Constantin–Fefferman（1993） · Majda–Bertozzi（2002）。

声明边界：本页证明的是精确差分恒等式、近远场估计、最优分裂半径、仅用 \(L^2\) 与 \(\dot H^1\) 范数时的指数唯一性，以及最优 Young 六次余项。它没有排除有符号跨尺度抵消或加入第三个临界量的估计，没有证明全局正则性或有限时奇性，也没有解决千禧年问题。
