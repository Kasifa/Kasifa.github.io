00 / Direct verdict

增长维数本身不能挽救 R0.71W 的小耦合预设根机制

本节判断

ECT inverse 不是这条上界的前置条件。exact root 上的 diagonal heat coordinate 正好为零，目标斜率只是 shear multiplication operator 作用于 active scalar 后的一个坐标。全演化又是 \(\ell^2\) contraction。由此可以在不求 interpolation inverse 的情况下直接结算 selected slopes。

结果关闭 uniformly small Dyson/IFT corridor 内的 selected prescribed-root 增益，也关闭 bounded coupling 下每个至多线性增长的 sampled-root 集。它不控制未知的全部 nonlinear roots。

01 / Exact setting

定理使用实 shear、单位载波相位和完整增长成本

令 \(M=2N+1\)，取互不相同的正整数 \(r_1,\ldots,r_M\)，launch vector 的 \(M\) 个非零系数均为单位模。scaled active sector 满足

\[ \partial_xF=D_qF+\frac P{q^2}V_z(x)F,\qquad \|F(0)\|_2^2=M. \]

实 shear 使 \(V_z(x)\) skew-adjoint，\(D_q\) self-adjoint 且 nonpositive，因此

\[ \|F(x)\|_2\le\|F(0)\|_2=\sqrt M. \]

matched background 必须支付 \(E_N=S^2K_{s,N}+P^2K_{v,N}\) 的全部增长成本；旧的 fixed-\(N\) background 不能免费复用。

02 / Root-coordinate identity

在 exact root 上，目标斜率由观测层算子直接控制

设 \(F_0(\tau_m)=0\)，并定义

\[ \Omega_N=\sup_{x\ge A_0}\|V_z(x)\|,\qquad \delta_{\rm obs,N}=\frac P{q^2}\Omega_N. \]

由于 \(D_q\) diagonal，根坐标的 heat term 消失。物理时间斜率精确为

\[ \partial_t\widehat f(k_*,t_{m,q}) =SP\,P_0V_z(\tau_m)F(\tau_m). \]

于是 exact nonlinear sampled-slope mass 满足 \(G_N^{\rm ex}\le NM\Omega_N^2\)。这里没有 Gronwall 指数，也没有 ECT determinant 或 inverse-Jacobian 常数。

03 / Selected-root theorem

完整支付后，selected-root endpoint ratio 至多为 \(N^{-1}\)

假设存在与 \(q,N,S,P,z\) 无关的 \(c_D,c_Y>0\)，使 \(D_N\ge c_Dq^2E_N\)，并在每个 counted root 有 \(Y_N(t_{m,q})\ge c_Yq^2E_N\)。则

\[ \boxed{ \frac{\mathcal J_N^{\rm sel}} {D_N^{1/3}\Lambda_1(I;u_N)} \le C\nu^{-2}\frac{\delta_{\rm obs,N}^{4/3}}N.} \]

因此 bounded \(\delta_{\rm obs,N}\) 给出 vanishing selected ratio。非消失至少要求 \(\delta_{\rm obs,N}\gtrsim N^{3/4}\)；发散要求 \(\delta_{\rm obs,N}/N^{3/4}\to\infty\)。\(\Lambda_1\ge\nu^2\) 已保留完整黏性 baseline；full-frequency rotational charge 只会增大分母。

04 / Lattice and amplitude cost

载波格点的 \(N^3\) 成本压过 \(N^2\) 的最坏采样和

互异正整数和单位相位强制

\[ K_{s,N}\ge\sum_{j=1}^{2N+1}j^2,\qquad \frac{N(2N+1)}{K_{s,N}}\le\frac3{4N}. \]

Fourier multiplier upper bound 给 \(\Omega_N^2/K_{v,N}\le2\pi^2K_z^2/3\)。再对 scalar/shear amplitude ratio 优化，极值位于 \(S^2K_s/(P^2K_v)=3\)。这三步合成上面的 \(N^{-1}\) bound。

05 / R0.71X corrigendum

观测耦合、Dyson exposure 与 IFT certificate 必须分开

R0.71X route matrix 中一个 lower comparison 需要修正。因为 operator supremum 从 \(A_0>0\) 开始，正确下界是 heat weighted：

\[ \Omega_N\ge c \left(\sum_l|z_l|^2e^{-2\nu d^2r_l^2A_0}\right)^{1/2}. \]

没有统一的 unweighted \(\|z\|_2\) lower bound。R0.71X 的 fixed-dimensional endpoint theorem 没有使用这个错误比较，因此其定理不受影响。

launch-to-root Dyson size 是 \(\eta_{\rm Dyson,N}=(P/q^2)\int_0^{\tau_N}\|V_z(x)\|dx\)。完整 quantitative IFT certificate 还要支付 inverse Jacobian 与 derivative-Lipschitz 常数。固定 \(A_0>0\) 时只有已审计的单向控制 \(\delta_{\rm obs,N}\le C_{A_0,\nu,d}\eta_{\rm Dyson,N}\)；反向不成立，\(A_{0,N}\to0\) 时常数退化。

06 / Separated-root enhancement

根间隔可以把 bound 从 \(N^{-1}\) 改善到 \(1/(h_NN^2)\)

设 \(h_N\) 是 scaled roots 与左边界之间的最小间隔，并令 \(W_N^2=\sum_l|z_l|^2e^{-2\nu d^2r_l^2A_0}\)。exact finite-\(q\) estimate 为

\[ G_N^{\rm ex}\le\frac{|K_z|^2M}{\nu d^2h_N}W_N^2,\qquad \frac{\mathcal J_N^{\rm sel}}{D_N^{1/3}\Lambda_1} \le C\frac{\delta_{\rm obs,N}^{4/3}}{h_NN^2}. \]

fixed \(h_N\) 给 \(N^{-2}\)，quasi-uniform \(h_N\asymp N^{-1}\) 回到 \(N^{-1}\)。若第一个根贴在 \(A_0\)，只有这个 \(h_N^{-1}\) corollary 退化，原 weighted-kernel form 仍成立。

07 / Additional-root boundary

一般 \(M\) 个 carriers 与 \(R\) 个 sampled roots 只得到条件支付

\[ \frac{\mathcal J_R}{D^{1/3}\Lambda_1} \le C\frac{R\delta_{\rm obs}^{4/3}}{M^2}. \]

bounded coupling 下，任何 extra-root escape 至少要有 \(R\gtrsim M^2\)。但本节没有证明全部 nonlinear target zeros 的数量上界，所以不能把这个条件结论写成 complete all-root theorem。

08 / Equal-grid ECT conditioning

ECT 仍决定 exact roots 是否能稳定构造，只是不进入上界证明

equal-grid roots \(\tau_m=mh\) 令 \(x_l=e^{-2\nu d^2hr_l^2}\)。integrated-response matrix 精确分解为 cumulative-sum、Vandermonde 与 diagonal factors，因此

\[ |\det\mathsf M|=(2\nu d^2)^{-N} \prod_l\frac{1-x_l}{r_l^2}\prod_{i<j}|x_i-x_j|, \]
\[ \|\mathsf M^{-1}\|_2\ge h^{-1}(2\nu d^2h\,r_{\max}^2)^{-(N-1)/2}. \]

canonical \(r_l=l\) 和 \(hN^2\to0\) 会产生快速 inverse growth。这是 conditioning squeeze，不是 true nonlinear IFT branch radius 的上界。

09 / Independent checks

解析链和两个独立计算层已分别核对

90 位 Decimal producer 通过 13/13：包括 amplitude optimizer、multiplier bound、\(N^{-1}\) 与 \(N^{-2}\) envelopes、临界 \(N^{3/4}\) coupling、heat-weighted correction 和 equal-grid inverse lower bound。

独立 NumPy/SciPy finite-matrix reconstruction 通过 12/12：skew defect 为零，semigroup contraction、root slope、multiplier、optimized envelope、separated bound、determinant factorization 与 inverse lower bound 全部通过。它们是 finite algebraic corroboration，不是 DNS，也不构造 growing exact-root family。

10 / Primary-source boundary

ECT、Vandermonde 与 quantitative IFT 文献只支持各自声明的层级

Karlin–Studden和Pinkus支持 finite-dimensional Chebyshev / total-positivity nondegeneracy；Gautschi与Gautschi–Inglese说明 positive-real Vandermonde inverse 会支付节点和维数损失。

Borwein–Erdélyi给 exponential-sum sampling inequalities；Cannarsa–Martinez–Vancostenoble量化 moment-method 的时间与 gap 代价；Phan Phien把 inverse Jacobian 与 Lipschitz data 放进 certified IFT radius；Koev说明 structured total-nonnegative computation 与普通 condition number 需要区分。

这些一手来源没有给出本节的 NSE root-coordinate identity、matched-background ledger、\(N^{-1}\) payment 或 all-root count。限定检索不构成原创性、优先权或不存在性声明。

12 / Research value

这是一项明确的路线关闭结果，不是千禧年问题的局部解答

R0.71X 表明 fixed-dimensional small-coupling family 可以达到 \(D^{1/3}\) endpoint。R0.71Y 证明仅增加预设根和 carrier dimension，在支付 exact observation operator、完整 lattice cost 和 matched floor 后，反而产生 \(N^{-1}\) suppression。ECT conditioning 不再是判断 selected-root gain 的前置瓶颈。

这把后续搜索压缩到更具体的例外：quadratic extra-root proliferation、floor-free or sparse-phase ledger、strong observation coupling、\(A_{0,N}\to0\) short pulse、non-unit phases 或不同 geometry。它没有缩小一般三维潜在奇性解的集合。

13 / Next finite gate

R0.71Z 检查 total-root count 与 floor-free complete ledger

下一节先判断 exact triangular nonlinear target coordinate 的全部实根能否由 carrier dimension、observation coupling 和 observation-layer geometry 统一计数。若不能，就寻找至少 quadratic root proliferation 的可复核候选。

并行检查 matched background 是否可以移除，或被 weak-solution / full-ledger quantity 自动替代。strong coupling、\(A_0\to0\) 与不同 geometry 仍按独立接口处理。

14 / Claim boundary

本节证明什么，也明确不证明什么

  • 已证明：在声明的 real-shear、fixed-target、unit-phase、matched-floor triangular setting 中，任意 selected \(N\) 个 exact roots 满足 \(C\nu^{-2}\delta_{\rm obs}^{4/3}/N\) upper bound；bounded coupling 下该比值消失。
  • 条件推论：非消失需要 \(\delta_{\rm obs}\gtrsim N^{3/4}\)；一般 \(R/M\) 账本下，bounded-coupling escape 至少需要 \(R\gtrsim M^2\)。
  • 仍开放：all-root count、floor-free / sparse-phase / non-unit-phase、strong coupling、\(A_{0,N}\to0\)、quadratic extra roots 与不同 geometry。
  • 没有得到：universal endpoint、继续性判据、有限时奇性、global regularity、原创性或优先权结论。
