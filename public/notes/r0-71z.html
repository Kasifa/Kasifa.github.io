不再数根：
全部根的斜率质量按 \(M^{-2}\) 被完整账本吸收

R0.71Y 只控制 selected roots，留下 \(R\gtrsim M^2\) 额外根和 matched root-time floor 两个接口。本节把目标改成 complete squared-slope mass。对实 shear、单位模 launch phases、固定 target 与 \(A_0>0\)，有界变差采样、exact \(\ell^2\) contraction 和 dissipative target row 给 \(G_{\rm all}^{\rm ex}\le C M\Omega^2(1+\delta_{\rm obs})\)。根仍在原观察区间计数，但 \(\Lambda_1\) 的付款区间包含 launch；\(\mathcal R_Y\) 随即把逐根分母换成 \(\sup Y\)。因此 bounded coupling 下 complete ratio 为 \(O(M^{-2})\)。

00 / Direct verdict

quadratic extra-root escape 在声明的 bounded-coupling 三角类中关闭

本节判断

raw root count 不是正确对象。R0.71U 已经表明有限 recurrence 数可以任意大。本节改为对每个 exact root 的 squared slope 求和；多重根和聚点型零根的斜率为零，不产生 atom 质量。

\[ \boxed{\frac{\mathcal J_{\rm all}(I)} {D^{1/3}\Lambda_1(K)} \le C\nu^{-2} \frac{\delta_{\rm obs}^{4/3}(1+\delta_{\rm obs})}{M^2}, \qquad K=[\sigma_q,b]\supset I.} \]

这是 declared exact triangular class 的 complete all-root upper bound，不是 general 3D NSE endpoint。

01 / Exact setting

实剪切给 exact contraction，并把一次导数变成耗散预算

\[ F'=D_qF+\delta V_z(x)F,\qquad \delta=P/q^2,\qquad \|F(0)\|_2^2=M. \]

实 \(z_l\) 使 \(V_z\) skew-adjoint，\(D_q\) self-adjoint nonpositive。因此

\[ \|F(x)\|_2\le\sqrt M,\qquad \int_0^\infty-\langle D_qF,F\rangle\,dx\le M/2. \]

观察耦合定义为 \(\delta_{\rm obs}=|\delta|\Omega\)，其中 \(\Omega=\sup_{x\ge A_0}\|V_z(x)\|\)。

02 / Bounded-variation sampling

相邻两个零点让导数在间隔上的平均值精确为零

若复标量 \(g\in W^{2,1}(a,b)\) 且 \(g(\tau_m)=0\)，则

\[ \sum_m|g'(\tau_m)|^2 \le |g'(\tau_1)|^2+ \|g'\|_\infty\int_a^b|g''(x)|\,dx. \]

证明只用 \(\int_{\tau_{m-1}}^{\tau_m}g'=0\) 和一次分部积分。常数不含 root count、minimum gap 或 fill distance，也不使用 vector-valued Rolle theorem。

03 / Dissipative target row

\(V_z'\) 与 \(V_z(D_q+\lambda_0)\) 必须合并后估计

令 \(h=P_0V_zF\)。目标积分因子 \(g=e^{\lambda_0(x-A)}F_0\) 满足

\[ g''=\delta e^{\lambda_0(x-A)} \left\{QF+\delta P_0V_z^2F\right\}, \qquad Q=P_0[V_z'+V_z(D_q+\lambda_0)]. \]

\(Q\) 只取 \(F_{\pm r_l}\)，精确系数含 \(-2\nu d^2r_l^2\mp2\nu dr_lK_y/q\)。一个 \(r_l\) 由 shear heat decay 支付，另一个由 \(-\langle D_qF,F\rangle\) 支付，得到

\[ \int_{A_0}^\infty|QF|\,dx\le3\Omega\sqrt M. \]

这一步避免了全局 \(\|D_qF\|_2\) 和不必要的 second spectral moment。

04 / Complete all-root theorem

全部 exact roots 的 squared slope mass 与根数无关

\[ \int_{A_0}^\infty\|V_z(x)\|\,dx \le C_\kappa\Omega,\qquad C_\kappa=\frac{\pi^2}{\sqrt{45}\nu d^2}. \]

结合 BV lemma、target-row estimate 和 \(\|F\|_2\le\sqrt M\)，对任意有限根子集都有

\[ \sum_{F_0(\tau)=0}|F_0'(\tau)|^2 \le e^{2\lambda_0L}(4+C_\kappa\delta_{\rm obs}) \delta_{\rm obs}^2M, \]
\[ G_{\rm all}^{\rm ex} \le e^{2\lambda_0L}(4+C_\kappa\delta_{\rm obs}) M\Omega^2. \]

再对所有有限子集取上确界即可处理完整零集；不需要先证明 zero-count theorem。

05 / Enstrophy-floor cancellation

先使用 \(\mathcal R_Y\)，再取黏性 baseline

对包含所有 counted roots 的付款区间 \(K\)，公共因子 \(1/\mathcal R_Y(K)\) 可以线性分配进 atom sum：

\[ \frac1{\mathcal R_Y(K)} \sum_m\frac{|h_m|^2}{Y(t_m)} \le\frac{\sum_m|h_m|^2}{\sup_KY}. \]

若 \(K=[\sigma_q,b]\) 包含 launch，则 \(\sup_KY\ge Y(\sigma_q)\gtrsim q^2(S^2K_s+P^2K_v)\)。所以 normalized ledger 不再需要 matched persistent background 或每个根时刻的单独 floor。

06 / Mixed-window boundary

根仍在 \(I=[a,b]\) 计数，只有付款区间扩到 launch

pre-observation layer 可能有其他根，并且不受 \(\Omega=\sup_{x\ge A_0}\|V_z(x)\|\) 控制。因此本节不把 root set 从 \(I\) 扩到 \(K\)。

若坚持只在 \(I\) 上计算 \(\Lambda_1\)，结果必须多付 retention factor

\[ \theta_I^{-1},\qquad \theta_I=\frac{\sup_IY}{q^2(S^2K_s+P^2K_v)}. \]

exact heat shear 给 \(\theta_I\asymp e^{-2\nu d^2R^2A_0}\to0\)。它只否定 automatic retention，不是具有非零 target atom 的完整反例。

07 / Endpoint scaling

unit phases 的 \(K_s\gtrsim M^3\) 把 complete ratio 压到 \(M^{-2}\)

amplitude ratio 的最大值仍在 \(S^2K_s/(P^2K_v)=3\)。再用

\[ \frac{\Omega^2}{K_v}\le\frac{2\pi^2K_z^2}{3}, \qquad K_s\ge\frac{M(M+1)(2M+1)}6, \]

得到 complete all-root \(M^{-2}\) suppression。大 coupling 下，这个 upper bound 的 nonvanishing diagnostic 是 \(\delta_{\rm obs}\asymp M^{6/7}\)；它不是 strong-coupling exact-root construction。

08 / Independent certificates

高精度代数和独立 finite-matrix 重建承担不同职责

Decimal producer 与独立 binary64 / finite-matrix certificate 已分别通过。前者检查 \(M^{-2}\)、\(M^{6/7}\)、optimizer、floor identity 与 retention；后者重建 shift matrices、\(Q\) row、dissipative payment 和 complex BV zero sampler。

两组计算都不是 DNS，也不构造 growing-dimensional exact-root family。continuum theorem 由解析证明承担。

09 / Primary-source boundary

finite ECT、maximal regularity 与 time analyticity 都不能替代本节估计

Narcowich–Ward–Wendland的 scattered-zero Sobolev inequality 支付 fill distance，不给本节的 discrete derivative mass。Acquistapace–Terreni和Pazy提供抛物演化框架，但 bounded time dependence 本身不推出 \(H_t^2\)。

Aldaz–Kounchev–Render的 ECT 是 fixed finite-dimensional kernel；Phillips的 Dyson–Phillips 是 infinite iterated-integral series，不能直接继承统一根数。Masuda与Giga–Jo–Mahalov–Yoneda支持 time analyticity，但不给 \(M^{-2}\) all-root payment。

限定的一手检索没有发现同形定理；这不构成原创性、优先权或不存在性声明。

11 / Research value

R0.71Y 的两个具体漏洞在同一声明类中同时关闭

第一，quadratically many extra roots 不再重要，因为 slope mass 直接求和。第二，matched floor 不再需要，因为 launch-inclusive \(\mathcal R_Y\) 自动把根分母转成一次 \(\sup Y\) retention。

这是一项严格的机制排除结果，但只覆盖 exact triangular 2.5D class。它没有缩小一般三维潜在奇性机制的集合，也没有给出继续性判据。

12 / Next finite gate

R0.72A 检查 strong coupling 与 shrinking observation layer

下一节优先判断 \(\delta_{\rm obs}\) 增长到 \(M^{6/7}\) 附近时，能否同时构造 exact roots、控制 full nonlinear rotational charge，并保持 IFT / Dyson certificate。

\(A_{0,M}\to0\)、sparse or non-unit phases 和 non-triangular geometry 分开登记，不把多个未闭合机制混成一个结论。

13 / Claim boundary

本节证明什么，也明确不证明什么

  • 已证明：declared triangular class 的 complete all-root squared-slope mass；launch-inclusive mixed-window floor cancellation；bounded coupling 下 \(M^{-2}\) endpoint suppression。
  • 已排除：在同一声明类中，仅靠 quadratic extra roots 或 matched background 逃逸。
  • 仍开放：strong coupling、\(A_0\to0\)、non-unit/sparse phases、complex shear、non-diagonal target 与不同 geometry。
  • 没有得到：raw zero-count theorem、universal endpoint、继续性判据、有限时奇性、global regularity、原创性或优先权结论。
