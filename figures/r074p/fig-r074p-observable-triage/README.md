# Figure package: R0.74P observable triage

This is the formal double-column figure package for R0.74P. It renders a
deterministic analytic comparison from the frozen proof and exact rational
ledger. It is not a simulation.

Run the two commands in command.txt from the repository root. The first
generates the CSV, vector PDF/SVG, 600 dpi PNG, environment record, results,
and progress log. The second verifies formulas, dimensions, required text,
hashes, and creates the final manifest and QA derivatives.

The package uses a restrained three-root palette and uses line style, direct
labels, table symbols, and text classifications so that meaning does not
depend on color. The archived PDF and SVG are the vector masters.  The SVG
declares its physical size in millimetres and embeds the archived regular
and bold fonts.

lower detection gate and fixed-scale weak stability, but its full upper
bound remains open. **NOT CLAY.**
