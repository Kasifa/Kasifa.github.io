# fig-r071s-signed-packet

Paper-ready four-panel figure package for R0.71S. It contains exact and
independent certificates, the plotting table and metadata, producer and
independent validators, vector PDF/SVG, a 600 dpi PNG, checksums, and
color/grayscale QA previews.

Run the commands in command.txt from the repository root. This is an exact
finite packet and forced-parabolic method audit. It contains no DNS and no
PDE time stepping. Panels A--C are exact packet or linear heat models. Panel
D is not a Navier--Stokes trajectory.
