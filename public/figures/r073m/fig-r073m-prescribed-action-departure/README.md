# Figure R0.73M — prescribed-action departure diagnostic

This is the formal static figure package for the sealed finite R0.73M
diagnostic. `source-data.csv` is deterministically derived from the sealed
primary, independent-linear, and independent-hierarchy JSON outputs. PDF and
SVG are vector exports; PNG is rendered at 600 dpi. The QA surfaces include
final-size, grayscale, and independently rasterized PDF views.

The figure checks the finite action-normalized gain, the registered
second-/third-order recoding, signed cubic path alignment, and maximum
discrepancy-to-tolerance ratios. It does not establish a continuum prefactor
limit, a two-term WKB expansion, a uniform Taylor radius, a full nonlinear
trajectory, fixed-background Lyapunov instability, transverse three-
dimensional closure, finite-time singularity, or the Clay problem.
