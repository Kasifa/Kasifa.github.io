# R0.73G finite nonlinear row-leakage diagnostic

This package evaluates a deliberately limited question for the frozen
R0.73F kinetic matrix at \(d=0\), \(\gamma=1/2\), and \(\mu=1/4\): how
large are two quadratic Navier--Stokes interactions generated by the actual
finite top eigenprofile?  Every stored number is an IEEE-754 binary64 finite
diagnostic.  The package is not an interval computation and is not a
continuum theorem.

The formal grid is

- cutoffs \(N=24,48,96,128\), with modes \(-N,\ldots,N\);
- \(\epsilon=10^{-2},5\times10^{-3},2\times10^{-3},10^{-3},
  5\times10^{-4},2\times10^{-4},10^{-4}\);
- positive-row normalization \(\|u_+\|_{L^2}=1\).

`nonlinear_row_leakage_rows.csv` contains all 28 cases and
`nonlinear_row_leakage_convergence.csv` contains adjacent-cutoff
comparisons.  `manifest.json` binds all six scientific outputs by SHA-256;
the scientific summary binds its five companion outputs.  The journal-style
figure is supplied as vector PDF/SVG and 600 dpi PNG.
`progress.ndjson` is the complete stdout of the recorded formal producer run.

## Quantities and normalization

The physical positive row is

\[
u_+(y,z)=(0,v(2y),2i v'(2y))e^{iz}.
\]

The reported physical \(H^3/L^2\) cost uses the Bessel-potential multiplier
\((1+|k|^2)^{3/2}\).  The \(K_z=2\) quantity is the projected quadratic
interaction of the unit positive row with itself.  The principal \(K_z=0\)
quantity uses the unscaled real pair \(u_++\overline{u_+}\), whose \(L^2\)
norm is \(\sqrt 2\); the summary also records the corresponding unit-real-pair
value.

Two kernels are cross-checked in the producer: reduced one-dimensional
identities and generic Fourier convolution followed by modewise Leray
projection.  `independent_validation.py` does not import the producer.  It
reconstructs the Orr--Sommerfeld matrix directly and checks five sentinels on
an alias-free physical grid using FFT and an independently written Leray
projection.

## Reproduction

Run the two commands in `command.txt` from the repository root.  The producer
enforces the source-before-run gate: its working source must match source
commit `21c11ba3eef7f2b5dc3f107957e0744a0471745d`.  The recorded run used local
dense CPU linear algebra; the largest matrix is only 257 by 257, so a DGX
would add transfer and orchestration overhead without improving this job.
Pinned package versions are in `requirements.txt`.

Verify the package ledger with

```sh
cd experiments/r073g
shasum -a 256 -c SHA256SUMS
```

## Evidence boundary

These computations use the actual finite top eigenprofile and show nonzero
projected row leakage with close finite-cutoff agreement.  That agreement is
not a Fourier-tail enclosure.  The results do not prove that the finite top
mode is the continuum top mode, do not prove a uniform continuum \(H^3\)
bound, do not establish nonlinear instability or a transition threshold, and
do not address three-dimensional vortex stretching.  They do not solve any
part of the Clay Navier--Stokes regularity problem.
