# 临界紧性小节：压力输入可以删去，刚性出口仍未成立

2026-09-06。**CONDITIONAL RESULTS / KNOWN-METHOD SCREEN / G OPEN / NOT CLAY。**

这一小节没有扩大已证明的三维 NS 正则解类。我完成的是一个有明确
假设的紧性命题、一个原解来源下的能量原子必要条件，以及已知
无原子端点的周期核验。已知定常 Euler 流则排除了过宽的刚性猜想。

## 1. 四个结果应分开读

1. **BK：缩放适用性。** 能量单独使 \(\beta\ge2/3\) 的所选短窗
   三次质量消失；若另有局部加权梯度界，\(\beta>1/2\) 也消失。
   \(\beta=1/2\) 是能量保持的边界，不等于所需梯度界已成立。
2. **BL：条件紧性。** 同一固定初值周期解的临界 Euler 缩放，
   若每个固定柱体上无权梯度一致有界，且单位短窗三次质量有正下界，
   则压力不必另加假设。完整周期规范压力局部 \(L^{5/3}\) 有界，
   子列速度在整个短窗强 \(L^3\)，压力强 \(L^{3/2}\)。
   极限非零、古老、全空间有限能量，具有局部能量等式。
3. **BM：宽类反例与原子必要性。** Gavrilov 的已知光滑紧支撑
   定常流符合这个宽 Euler 类，因此一般全零刚性是错误的。
   但它未被证明能从上述固定 NS 历史产生。另一方面，BL 的两个
   速度假设若在同一原解实现，会迫使终端能量测度出现正原子。
4. **BN：已知端点的周期重算。** 原解若在该点的一个固定邻域额外
   属于强 \(L^{11/3}_{t,x}\)，则终端能量测度在该点无原子。
   证明保留完整压力和终点测度，只是已知机制的周期小球核验。
   基本能量给 \(L^{10/3}_{t,x}\)，未支付这个额外端点。

## 2. 实际减少了哪一个条件

BL 在已假设的速度预算下删去了独立压力预算，并处理了两处
容易遗漏的极限：

- 先固定源半径，再取扩张胞极限，最后令源半径趋于无穷；
  规范压力没有留下任意时间常数或调和余项。
- 紧性直接在整个 \((-S,0)\) 时间窗成立，且有终点薄层一致可积；
  非零质量不是仅在远离终点的子区间被观察到。

这是一项条件性技术输入减少，不是 G、原带符号压力功上界或
任意初值正则性所需输入的减少。局部能量等式也没有升级为
一般全空间能量守恒。

BM 的原子结论直接使用原解终端能量测度，不通过 Euler 刚性。
若单位短窗三次积分至少为 \(\varepsilon_*\)，对应 \(10/3\)
积分至多为 \(V\)，则某个终端能量原子至少为
\(\varepsilon_*^4/(2V^3)\)。它是条件必要性，不是原子存在证明。

## 3. 原文核对改变了后续选择

我不再把“有限能量古老 Euler 解全零”列作待证定理，
因为原文已有真实定常反例。也不把已有无原子定理当成自动出口：
所查两篇原文仍有额外强/弱可积性或 Type I 假设，并须分清端点。
这只是有界核查，不是对所有文献的穷尽性否定。

BN 的强 \(11/3\) 端点证明消除了一个具体周期移植疑问，
没有消除额外速度输入。原解仅有能量指数时，同一测试的绝对值
估计仍留下 \(r^{-3/10}\) 和 \(r^{-9/20}\) 的因子。
不能用积分趋零但无速率，直接抵消这些负幂。

## 4. 下一步只检查原子与总耗散的关系

下一个问题从 BM 已构造的唯一终端能量测度开始：
**假设真实固定原解有一个正能量原子，能否从完整局部能量平衡
推出总耗散不允许的下界？**

我先核对已有能量浓集记录，保留固定中心、原时钟、规范压力、
全部截止项和有符号通量。先把原子如何约束每个小半径的时间窗口
写成有序量词，再判断这些窗口的耗散成本是否真能累加。
不得把嵌套窗口当作互不相交，也不得从单个时刻的球内能量
推出未经证明的持留宽度或预定幂率。

若只得到与有限总耗散相容的成本，就结束这项原子耗散测试；
不自动改扫邻近 \(p,q\)，也不把 scalar 能量族当成 NS 反例。
只有真实原解约束减少了一个既有未付条件，才考虑后续一般正则出口。
即使证明无原子，也必须另处理任意候选奇点是否生成 BL.3，
不能将这一条条件分支重新定义为 Clay 问题本身。
