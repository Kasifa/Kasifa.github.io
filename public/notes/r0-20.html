00 / Result boundary

有限模型的局部缺口已经变成全局定理

PROVED恰有两个正内部驻点

两个根盒各含唯一根；其余正内部由完整 Bernstein 细分排除。

PROVED唯一全局最大点

目标能量比例最大值为 \(5.9518698677219236\ldots\%\)。

PROVED全部边界闭包更低

最大边界值为 \(3.280940959752690\ldots\%\)，位于 \(q=0\) 面。

OPENPDE 桥梁没有建立

Taylor 余项、热耗散、逐壳动力学和无限维稳定性仍未控制。

本笔记的严格结论。 对 R0.18–R0.19 所定义的正三参数第五阶商，令 \[ J(p,q,x)=\frac{T(p,q,x)}{T(p,q,x)+E(p,q,x)}, \qquad (p,q,x)\in(0,\infty)^3. \] 把 \(J\) 连续延拓到紧化闭包 \([0,\infty]^3\)。该闭包上存在唯一全局最大点； 它位于第 3 节第一个根盒内。正内部只有另一个驻点，且它是非退化鞍点。

这里的“严格”是指证书链中的有理代数、区间包含与外向舍入符号排除； “有限模型”则是不可省略的限定。这个结论没有证明三维 Navier–Stokes 解的全局正则性或有限时奇性。

01 / Quotient and compactification

先把无界正八分体变成闭立方体

\(T\) 是目标频率能量，\(E\) 是模型中其余频率的能量。 R0.18 使用的外部/目标比 \(R=E/T\) 与这里的目标比例满足 \(J=1/(1+R)\)， 所以 \(R\) 的极小点就是 \(J\) 的极大点。为处理全部无穷端，我使用射影坐标

\[ u=\frac{p}{1+p},\qquad v=\frac{q}{1+q},\qquad w=\frac{x}{1+x}. \]

正内部变成 \((u,v,w)\in(0,1)^3\)，而 \(p,q,x\) 的零端和无穷端成为闭立方体的面。 原始 Laurent 树聚合出 332 个频率，未抵消的 Laurent 单项式数为零。 \(T\) 含 169 项，\(T+E\) 含 1,027 项；其精确有理系数与摘要保存在证书包中。

02 / Saturated stationary system

候选搜索与完备性证明承担不同职责

内部驻点由三个商导数分子给出：

\[ F_p=T_p(T+E)-T(T+E)_p, \quad F_q=T_q(T+E)-T(T+E)_q, \quad F_x=T_x(T+E)-T(T+E)_x. \]

原始三个多项式分别含 4,025、4,025 与 3,750 项。 我精确除去在正内部不产生孤立驻点的公共因子，再把所得饱和系统变换到 \((u,v,w)\) 立方体。 高精度 Newton/扫描只用于提出两个候选根；它不承担“没有漏根”的证明。

完备性的来源。 每个候选根由有理 Krawczyk 盒认证存在且唯一；根盒和两个退化边界条带以外的每个盒， 至少有一个驻点多项式的 Bernstein 系数区间严格同号。两条路径合并后才得到全域结论。

04 / Faces and edges

四个有限面用精确消元闭合

在 \(p=0,p=\infty,q=0,q=\infty\) 四个面上，我先计算精确 resultant， 再用 Sturm 根计数与有理单变量表示配对公共根。每个保留根由二维有理 Krawczyk 盒分类； 四条有限 \(p/q\) 边则各有且仅有一个正驻点，并且都是该开放边的严格全局最大点。

05 / Degenerate x-boundaries

两个退化点用加权放大与有限宽条带处理

直接在 \(x=0\) 和 \(x=\infty\) 上观察，驻点系统分别在 \((x,p)=(0,2)\) 与 \((x,q)=(\infty,3)\) 退化。仅知道边界极限的符号还不足以排除贴着边界进入内部的根， 因而我先作加权 blow-up，再把局部符号加强为显式条带：

\[ |p-2|\le\frac12,\quad 0<x\le\frac18,\quad q\ge0 \quad\Longrightarrow\quad F_x<0, \] \[ |q-3|\le\frac12,\quad x\ge4,\quad p\ge0 \quad\Longrightarrow\quad F_x>0. \]

两个严格符号均由有理张量 Bernstein 系数证明，且覆盖被全局立方体细分委托出去的两个 dyadic 核。 因此退化线附近也没有遗漏内部公共根。

06 / Global Bernstein completion

两次独立种子划分都以零未决盒结束

在紧立方体上，我为三个饱和驻点多项式预计算 Bernstein 张量， 对每个盒执行外向舍入符号测试；不能排除的盒沿最有信息的坐标二分。 根盒和第 5 节的两个条带作为已认证区域登记，不被浮点细分替代。

第一轮分别由三个方程排除 584、268、483 个叶盒；独立种子轮为 858、379、498 个。 两轮从不同初始划分到达相同的根盒、条带与零未决结论。 这不是通过密集采样“没有看见其他根”，而是对覆盖整个紧立方体的盒族逐盒给出符号证书。

07 / Finite-model theorem

紧致性把驻点分类与边界比较拼成全局结论

计算机辅助定理（所选第五阶模型）。 \(J\) 在紧化闭包上连续。其正内部恰有两个驻点；根 I 为严格局部最大，根 II 为鞍点。 所有边界闭包的最大值不超过 \(3.280940959752690\ldots\%\)，而根 I 的值位于 \(5.9518698677219236\ldots\%\) 的认证区间内。因此根 I 是 \([0,\infty]^3\) 上 \(J\) 的唯一全局最大点。

证明的逻辑链是：精确商与饱和系统 → 内部 Krawczyk 盒 → 有限面的精确消元与根配对 → 退化 \(x\) 端的精确符号条带 → 全立方体外向舍入 Bernstein 排除 → 边界数值区间比较。 每一环的机器可读输出均有 SHA-256 清单。

08 / Meaning and PDE gap

这是实质性的模型结果，但离千禧年问题仍有结构性距离

它的价值

  • 把 R0.18–R0.19 的一个局部候选升级为有完整边界处理的有限模型唯一全局最优点。
  • 建立了可复用的证书链：精确稀疏代数、Krawczyk 根盒、resultant/RUR 边界分类与全局 Bernstein 排除。
  • 给下一步 Taylor 余项估计提供了一个不再含参数寻优歧义的基点。

它没有给出的东西

  • 第五阶截断没有自动控制第六阶及以上的非线性余项。
  • 三参数极化族不等于所有散度自由初值，更不等于解轨道的无限维相空间。
  • 目标频率比例的有限阶增长没有证明可以跨壳重复，也没有压倒粘性热衰减。
  • 没有得到任何三维 Navier–Stokes 全局正则性、奇性形成或 Clay 问题结论。

因而，这一结果适合表述为“可独立复现的有限模型全局分类”，不适合表述为 PDE 进展定理。 它减少了机制探索中的一个自由度，但真正困难的无限维误差传播仍在前面。

09 / Next

下一步：把第五阶最优点放回带余项的短时 PDE 展开

  1. 在根 I 的认证盒上构造第六阶及更高阶 Duhamel 余项的显式范数上界，而不是只在盒中心估计。
  2. 把粘性热因子保留在每棵树的时间积分中，求出目标增长仍为正的严格时间窗。
  3. 对极化、振幅与相位的横向扰动给出统一稳定半径，明确哪些有限维限制仍是开放缺口。
  4. 只有单步含余项不等式闭合后，才研究尺度迭代、跨壳误差累积与可能的临界范数机制。

这一步以符号推导和高精度区间积分为主；若进入大量参数盒或三维谱验证， 我会使用 DGX 资源并持续记录进度、资源占用、检查点、原始数据及期刊级附图包。

10 / Reproduction

公开脚本、证书包与计算环境

全部机器可读证书位于 research/certificates/r020； SHA256SUMS 固定了本笔记使用的输入与输出。 正参数全局排除的主要复现命令是：

python3.12 research/positive_region_boundary_strip_audit.py --check --pretty
python3.12 research/positive_region_bernstein_exclusion.py --seed-depth 2 --workers 8
python3.12 research/positive_region_bernstein_exclusion.py --seed-depth 3 --workers 8

有限面消元使用固定镜像 navier-stokes-r020-flint:py312-flint090， 镜像 ID 以 sha256:02b6a511…f013a5 结尾；该部分在 DGX Spark 上运行。 全局细分使用本机 Python 3.12.13、NumPy 2.3.5 与 8 个进程。 正式附图包包含 CSV、来源摘要、绘图脚本、PDF/SVG/600 dpi PNG、caption、manifest 和独立数据校验器。

建议先运行证书包中的 SHA-256 校验，再重算根盒、边界与全局细分； 两个全局 JSON 应同时报告 complete=true 且未决盒为零。
