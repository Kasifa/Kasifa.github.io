研究笔记 R0.71B · COMMON RESPONSE · SIGNED OUTPUT GATE

common-response 保持阶一，
但不会自己变成尺度补偿

我构造了两个可以任意增加壳层数的精确 Fourier 扇形。第一个保留固定能量与正的总 common work，却让壳层 ℓ2 量趋于零；第二个在三个输入范数固定时让三场极化 common form 按 √N 增长。随后我定义了保留应变输出相位的正输出系数，并得到精确的 Cauchy–Young 耗散消费式。缺口也很清楚：目前没有从 Navier–Stokes 动力学推出该系数的时间可积性。

00 / Exact decision

response chord 的衰减不能转移给 common channel

R0.70Y–R0.70Z 已经把框架协方差功分成 common 与 chord 两条响应通道。R0.71B 的结论是：chord 在高–高–低区确有二次小量，但 common channel 仍可跨任意大的壳层间隔保持阶一。单个三波已经显示这个差异；两个多壳层族进一步排除“同号自然可求和”和“壳层上确界直接控制三场形式”这两个静态推理。

\[ \mathcal U_M\nearrow1, \qquad M^2\mathcal C_M\longrightarrow-\frac12. \]

本节同时留下一个更精确的候选量 \(a_+\)：它只记录协方差功在每个输出频率上的正贡献，并且能被黏性耗散消费。不过，静态定义与动力学闭合是两件事；这里没有得到 \(a_+\in L_t^1\)。

01 / One exact HHL atom

共同响应趋于一，响应弦只剩 \(M^{-2}\)

在归一化环面上取

\[ n=(1,1,0),\quad p_M=(M,-M-1,0),\quad q_M=(-M-1,M,0), \]
\[ c=\frac{(1,-1,0)}{\sqrt2},\quad a=e_3,\quad b_M=\frac{(M,M+1,0)}{\sqrt{2M^2+2M+1}}. \]

三频率精确共振，三个极化均无散；两个高频半径相等，并与低频严格响应分离。直接收缩得到

\[ \mathcal U_M= \frac{\sqrt2M(M+1)(2M+1)}{(2M^2+2M+1)^{3/2}}, \]
\[ \mathcal C_M= -\frac{\sqrt2(2M+1)}{2(2M^2+2M+1)^{3/2}}. \]

而且 \(\mathcal U'_M>0\)，\(M\ge4\) 时 \(\mathcal U_M>0.969\)。因此不存在随壳层间距趋零的统一 common-response 包络；R0.70Y 的 chord 增益仍然成立，但不能覆盖 common 部分。

02 / Same-low fan

同号不等于壳层打包定理

令 \(M_j=8^j\)，把同一个低频与 \(N\) 对严格分离的高频配对，并把每个高频振幅归一化为 \(N^{-1/2}\)。所得场只有预设的 \(12N\) 个有序共振，且总 \(L^2\) 质量始终为

\[ \|\omega_N\|_2^2=\frac32. \]

第 \(j\) 个壳层的 common work 为 \(w_j=\mathcal U_{8^j}/(4N)>0\)。因此

\[ \sum_{j=1}^Nw_j\longrightarrow\frac14, \qquad \Big(\sum_{j=1}^N|w_j|^2\Big)^{1/2} \sim\frac1{4\sqrt N}. \]

所有壳层贡献同号，仍然不存在与 \(N\) 无关的 ℓ2 到 ℓ1 升级。这个族并不排除真正记录全部打包质量的 Carleson 范数；它排除的是仅凭符号与共同响应凭空产生该质量。

03 / Shared-high fan

固定三个输入量，三场极化 common form 仍按 √N 增长

第二个族取 \(M_j=16^j\)，用有理圆参数制造一个共享高频 \(q\)、\(N\) 个同半径高频 \(p_j\) 与 \(N\) 个严格分离低频 \(n_j\)。全部频率是整数，\(|p_j|=|q|\)，并且没有非预设共振。对相应的无散场 \(A_N,B_N,C_N\)，

\[ \sup_\alpha\|T_\alpha A_N\|_\infty\le1, \qquad \|B_N\|_2=\|C_N\|_2=\frac1{\sqrt2}, \]

但精确的三场极化 common work 是

\[ \mathfrak P_{\rm cr}(A_N;B_N,C_N) =-\frac1{8\sqrt N}\sum_{j=1}^N \frac{M_j}{\sqrt{1+M_j^2}} \sim-\frac{\sqrt N}{8}. \]

所以不存在由上述壳层上确界与两个 \(L^2\) 范数给出的统一直接估计。这里否定的对象严格限于这个三场极化估计；它不否定已知的单场 Besov 混合估计，也不否定 Kozono–Ogawa–Taniuchi 的延拓判据。后者使用频率分解与高阶范数的对数因子，不依赖这个被排除的三场不等式。

04 / Tent and BMO boundary

普通正平方 tent 会吸收增长，却看不见符号

标准 Littlewood–Paley tent / Carleson 平方量在通常可容许分解下等价于 BMO（模常数）。共享高频族的根 tent 质量已经按 \(\sqrt N\) 增长，恰好足以吸收上一节的 \(\sqrt N\)；因此它不是更弱的新系数。

这个正平方量还对逐尺度符号翻转不变。R0.71A 的两个场逐点协方差相同、尺度平方质量相同，但协方差功符号相反，所以任何只依赖非负尺度平方的候选量都无法区分它们。反过来，只控制 tent 盒中的有符号总质量也不能直接调用经典 Carleson 嵌入，因为后者需要正测度或总变差控制。真正的替代物必须额外证明部分和、有界抛物算子或时间–尺度通量的伸缩结构。

05 / Positive-output coefficient

先保留应变输出的相位，再取正部

令 \(K_+\) 从每对 \(\{k,-k\}\) 中取一个代表，并在输出频率上定义

\[ w_k=2\operatorname{Re} \big(\overline{\widehat S(k)}:\widehat Q(k)\big), \qquad \mathfrak P_Q=\sum_{k\in K_+}w_k. \]

正输出平方与归一化系数取为

\[ \mathcal T_+^2= \sum_{\substack{k\in K_+\\\widehat S(k)\ne0}} \frac{(w_k^+)^2}{4|k|^2|\widehat S(k)|_F^2}, \qquad a_+=\frac{\mathcal T_+^2}{\|\omega\|_2^2}. \]

它通过 R0.71A 的同协方差符号测试：正场满足

\[ \mathcal T_+^2=\frac9{800}\Lambda^4, \qquad a_+=\frac3{39940400}\Lambda^2, \]

负场的 \(\mathcal T_+\) 与 \(a_+\) 都为零。一个非零无散单平面波则有非零 BMO / 平方振幅，却仍满足 \(a_+=0\)。所以 \(a_+\) 不是 \(Q\) 的函数，不是范数，也不等价于 BMO；它专门保留被协方差平方丢掉的应变输出相位。

06 / Cauchy–Young consumer

消费式精确成立，但还没有 Navier–Stokes 时间传播

由无散 Fourier 系数的恒等式与 Cauchy–Schwarz，正协方差功满足

\[ (\mathfrak P_Q)_+ \le\|\nabla\omega\|_2\mathcal T_+ \le\frac\nu4\|\nabla\omega\|_2^2 +\nu^{-1}a_+\|\omega\|_2^2. \]

这正好把四分之一黏性耗散用于吸收 \(\mathcal T_+\)。与 R0.70Y 的混合缺陷估计合并后可写成

\[ \frac12Y'+\frac{3\nu}{4}D \le\left[\nu^{-1}a_+ +C_{\mathscr T}\|\omega\|_{B^0_{\infty,\infty}}\right]Y. \]

然而，这只是确定性的消费不等式，不是闭合。Leray 能量、协方差主投影与本节的静态 Fourier 代数都没有推出 \(a_+\in L_t^1\)。上式中的 \(L_t^1\dot B^0_{\infty,\infty}\) 涡量条件本身已经是已知充分条件，所以把它与 \(a_+\) 并列不会得到新的延拓定理。本节没有给出新的无条件正则性结论。

07 / Literature boundary

经典调和分析给出坐标系，但不会自动制造所需的动态估计

Bony 的抛物分解分离低–高、高–低与共振项，但频率记账本身没有符号或打包定理。Coifman–Meyer–Stein 的 tent spaces、Fefferman–Stein 的 Hardy / BMO 理论与Frazier–Jawerth 的离散变换把标准正平方量放在 BMO 边界。

CLMS 的 div–curl Hardy 补偿配合 Hardy–BMO 对偶能在假定 BMO 系数以后控制伸长项，却不能从能量或协方差几何推出该系数。Kozono–Ogawa–Taniuchi 已经给出 \(L_t^1\dot B^0_{\infty,\infty}\) 涡量延拓判据；Koch–Tataru 的 \(BMO^{-1}\) 正 Carleson 量属于小数据临界理论，并不是大数据 common-response 的有符号抵消定理。

有限的一手来源检索没有在已核查文献中找到本节两个精确扇形或 \(a_+\) 的同一公式。这只是检索边界，不构成新颖性或优先权证明。

08 / Research value

价值在于精确分类路线，而不是改写 Clay 问题的已知边界

R0.71B 关闭了三条看似便宜的静态捷径：把 chord 衰减转给 common channel、把同号直接升级为壳层 ℓ1 控制、把三场 common form 交给一个壳层上确界与两个能量范数。每条否定都有任意 \(N\) 的解析族，并由 \(N=8\) 的完整有限 Fourier 枚举做回归检查。

正输出系数 \(a_+\) 的意义不同：它不是一个已经可控的新范数，而是把“缺失的符号信息”压成可被耗散消费的具体目标。它使下一步要证明的内容可以被精确陈述和反例测试。不过，本节没有改善已知无条件理论，没有证明奇性，也没有证明全局光滑性；对千禧年问题的作用仍是间接的路线筛选。

09 / Next analytic gate

R0.71C：在取平方之前做局部有符号化

下一步不是再定义一个普通正 Littlewood–Paley tent，而是把 \(w_k\) 的应变相位保留到局部包中，再检查嵌套 tent 的有符号部分和、相邻时间–尺度盒的通量伸缩，或 \(a_+\) 与横向残差之间的定量联系。

接受测试预先固定：新候选必须同时通过本节两个扇形与 R0.71A 的同协方差符号对，并与 BMO、dyadic-BMO 和 \(\dot B^0_{\infty,\infty}\) 判据逐项比较。如果它化简为标准正平方 tent，该路线就按 BMO 的经典重写归档。在局部化定义得到解析门槛以前，不需要 DNS、GPU 或 DGX。

10 / Claim boundary

已证、已排除与开放缺口分开记录

PROVED单原子的 common / chord 分离

common 符号趋于一，chord 符号按 \(M^{-2}\) 衰减。

PROVED同低频打包 no-go

固定能量与同号总功并不产生壳层 ℓ2 到 ℓ1 的统一升级。

PROVED三场极化壳层上确界 no-go

共享高频族排除一个特定三场直接估计；结论不延伸到已知单场 Besov 判据。

PROVED正输出 Cauchy–Young 消费式

\(a_+\) 通过 R0.71A 符号测试，并具有正确的临界时间量纲。

OPEN动力学时间可积性

尚无结论从 Navier–Stokes 方程推出 \(a_+\in L_t^1\) 或局部有符号部分和控制。

NOT CLAIMED新的延拓或全局正则性定理

静态 Fourier 族不是 Navier–Stokes 解轨道，也不是有限时奇性。
