# R0.71N journal figure package

This package archives the exact full-scalar square--residual identity, the
local filtered-enstrophy cancellation of the apparent positive square, two
deterministic finite-Fourier NSE initial-jet diagnostics, and the critical
scaling ledger used in R0.71N.

Panel A is exact fixed-cell algebra on \(Y>0\), \(d_Q>0\), with a fixed
time-independent cutoff. Panels B and C use two smooth, alias-safe,
finite-Fourier initial jets. Their values are deterministic diagnostics and
are not interval-certified sign theorems. Panel D records exact local
co-scaling exponents and identifies the R0.71O hard/soft denominator-face
gate; it asserts no face estimate.

The package contains 178 mm vector PDF and SVG exports, a 600 dpi PNG,
auditable source data, plotting and data-generation code, producer and
independent validation paths, color and grayscale QA previews, a visual QA
report, environment details, a manifest, and SHA-256 hashes.

No DNS, time stepping, fitted data, no-go theorem, continuation criterion,
regularity result, singularity result, originality claim, or
Millennium-problem conclusion is represented.
