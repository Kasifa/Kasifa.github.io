# R0.71M journal figure package

This package archives the exact annular-filter Lamb increment identity, the
fixed-cell projective-pairing ledger, an independent finite Fourier witness,
and the energy-to-critical-budget claim boundary used in R0.71M.

Panels A and B are deterministic binary64 diagnostics for one declared
finite-mode witness; they verify the displayed identities for that witness
but do not certify a sign on a continuous time interval. Panel C plots exact
analytic heat-packet exponents with coefficients normalized at radius one;
the packets are smooth divergence-free heat flows, not nonlinear NSE
solutions. Panel D records the direct proof-route boundary: the known
undifferentiated quartic defect does not close the displayed differentiated
four-row Cauchy/Bernstein ledger, while a whole-scalar signed fusion remains
open for R0.71N. This is not a logical non-implication between the defect and
the tangent.

The package contains PDF, SVG, and 600 dpi PNG exports, source data, two
validation paths, color and grayscale QA previews, provenance, and SHA-256
hashes.
