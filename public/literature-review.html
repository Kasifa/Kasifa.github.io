01 / Exact problem boundary

先把原问题说准确

Clay 问题不是“方程有没有解”，而是任意光滑无散初值产生的三维解能否永久保持光滑；负面答案则需要严格构造正式条件允许的有限时破裂。

\[ \partial_t u+(u\cdot\nabla)u-\Delta u+\nabla p=0, \qquad \nabla\cdot u=0, \qquad u(\cdot,0)=u_0. \]

正式表述允许在 \(\mathbb R^3\) 或三维周期空间 \(\mathbb T^3\) 上给出正向光滑性证明，也允许按规定的初值和外力给出崩溃例子。研究中通常把“无外力、任意光滑无散初值是否全局光滑”看作核心正则性版本。二维正则性、修改方程爆破、特殊对称解或带外力弱解非唯一性都不能直接替代这个版本。[1][2]

本综述的边界

我只把已发表定理写成已知结果；2026 年预印本单独标记；本站 R0.69P–W 只作为经过审计的研究笔记，不把它们外推成正则性定理。

02 / Critical-scale obstruction

为什么三维问题卡在临界尺度

全局能量估计足以构造弱解，却允许能量在越来越小的尺度上集中。三维独有的涡量拉伸又能把这种集中转成正的 enstrophy 生产。

\[ u_\lambda(x,t)=\lambda u(\lambda x,\lambda^2t), \qquad p_\lambda(x,t)=\lambda^2p(\lambda x,\lambda^2t), \] \[ \frac12\frac{d}{dt}\|\omega\|_2^2+\|\nabla\omega\|_2^2 =\int_{\mathbb R^3}\omega\cdot S\omega\,dx. \]

速度空间 \(L^3\)、\(\dot H^{1/2}\)、\(BMO^{-1}\) 以及一族临界 Besov 范数与方程缩放相容。小临界数据可以全局求解，大临界数据可以局部求解；如果潜在爆破前 \(L_t^\infty L_x^3\) 保持有界，则爆破不能发生。真正缺少的是：怎样从一般大数据的能量级控制，无条件推出某个这样的临界量全局有界。[5][6][7][8][10]

03 / Literature topology

五条主要理论分支

这些分支并不是彼此竞争的“解法”。它们从不同方向刻画：如果奇性存在，它必须逃过哪些控制。

CONDITIONAL REGULARITY

Serrin 与端点 \(L^3\)

若 \(u\in L_t^qL_x^p\)、\(2/q+3/p\le1\)，则相应区间正则；ESS 封闭了 \(p=3,q=\infty\) 端点。条件本身尚未由能量自动推出。[4][10]

PARTIAL REGULARITY

CKN 与 \(\varepsilon\)-正则性

适合弱解的奇异集具有零的一维抛物 Hausdorff 测度。潜在奇性很稀疏，但“稀疏”仍不等于“空集”。[11]

CRITICAL ELEMENT

浓缩紧性与刚性

若临界空间中存在爆破数据，可以尝试抽取最小爆破元，再用紧性和唯一延拓排除；框架仍需要临界范数先验有界。[12][18]

GEOMETRIC DEPLETION

涡量方向与中间应变特征值

方向相干或 \(\lambda_2^+\) 的临界控制足以得到正则性；目前它们仍是条件判据，不是一般解自动满足的结论。[19][20][21][22]

04 / Foundational results

经典理论骨架

把“存在、唯一、正则”分开后，问题的位置会清楚很多。

理论层级已经严格得到仍然缺少
Leray–Hopf全局有限能量弱解存在。[3][4]一般唯一性与全局光滑性。
临界局部理论临界空间局部解，小数据全局解。[5][6][7]任意大数据的全局临界界。
Serrin / ESS临界时空量有界则不爆破。[4][10]从能量自动推出临界量有界。
CKN奇异集极小，局部小量触发正则。[11]证明奇异集为空。
自相似排除排除一类经典后向固定剖面。[24][25]排除 Type II、形状变化和多尺度递归爆破。
几何耗散方向相干或应变特征值控制足以正则。无条件产生这些几何控制。
定量正则性爆破下界、浓缩尺度和奇点数控制。[13][14]把必要浓缩变成矛盾。
弱非唯一性较弱解类或带外力 Leray 解可非唯一。[27][28]这些结果不等价于无外力光滑初值的 Clay 核心问题。
05 / Blow-up exclusion tree

哪些爆破图景已被排除

已知结果对奇性施加了很强的必要条件，但开放区域仍包含非自相似、形状变化和多尺度递归的 Type II 图景。

Seregin 证明潜在爆破时刻前 \(\|u(t)\|_3\to\infty\)；Tao 又把端点正则性定量化，得到显式高阶界和三重对数型爆破下界。Barker–Prange 把 Type I 上界与空间浓缩、临界范数下界和奇点数量联系起来。这些结果更准确地描述“如果爆破，它必须怎样发生”，但还没有证明这种发生方式不可能。[13][14][23]

06 / Recent progress

2019—2026 年值得保留的进展

我不使用“已经接近解决”这样的判断，只按结果类型记录它实际推进了哪一条边界。

QUANTITATIVE

临界正则性的定量化

Tao 给出临界 \(L^3\) 控制下的显式高阶界和爆破下界；Barker–Prange 进一步连接 Type I 图景、局部浓缩和奇点数量。[13][14]

PARTIAL REGULARITY

CKN 的对数改进

Lei–Ren 对部分正则性作定量改进，并得到轴对称小旋量情形的应用；一般三维奇异集仍未证明为空。[15]

CRITICAL ENDPOINTS

Lorentz 与应变特征值条件

近年的工作把定量边界推进到临界 Lorentz 空间，并细化中间应变特征值的延拓条件；这些仍是条件正则性结果。[16][17]

两篇与当前路线直接相邻的 2026 年预印本

Yu 研究过滤涡量拉伸、增量缺陷、远场应变和局部化余项；Grujić 在特定临界浓缩与加权 BMO 涡量方向假设下给出对数耗散机制。两篇都与“增量—尺度—几何耗散”相邻，但截至资料截止日仍应标为预印本，它们给出条件机制，不是一般大数据全局正则定理。[29][30]

不能误读的两类结果

Tao 的平均 Navier–Stokes 模型爆破说明能量与缩放等粗结构不足以单独完成证明，但不是原方程的反例。Buckmaster–Vicol 与 Albritton–Brué–Colombo 的弱非唯一性定理有解类或外力边界，也不能替代无外力光滑初值的 Clay 核心问题。[26][27][28]

08 / Research judgment

从文献得到的研究判断

下一条值得投入的引理，不能只是又一个单时刻恒等式。它至少应同时通过下面六个门。

  1. 尺度正确。在 Navier–Stokes 缩放下临界或略次临界。
  2. 能量级可定义。适合弱解上有意义，不预先要求高阶光滑性。
  3. 保留符号。关键步骤不能过早取绝对值。
  4. 全空间结算。近场、远场、交换子和局部化边界都要纳入。
  5. 动态可迭代。沿时间或半径产生严格收缩，而非静态重写。
  6. 不循环论证。不能把想证明的临界控制重新当作假设。

DGX 仿真适合扫描形状参数、定位饱和族、保存中间积分块并寻找反例候选；它不能证明对所有光滑初值、所有尺度成立的统一不等式。我会继续采用“数值搜索候选结构 → 区间或精确证书 → 分析引理 → 接到适合弱解或临界空间”的顺序。
