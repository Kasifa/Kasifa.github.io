**Figure R0.73P -- critical-frequency gate and linear heat baseline.**
**A,** After normalizing the admissible radii to one, a perturbation supported
in Fourier modes \(|k|\leq N\) must obey an \(L^2\) amplitude threshold of
order \(N^{-3}\) for direct \(H^3\) entry, whereas a critical
\(\dot H^{1/2}\) entry argument asks only for order \(N^{-1/2}\). These are
different sufficient interfaces, not competing estimates for the same norm.
**B,** For a single normalized mode with amplitude
\(a_N=cN^{-\gamma}\), the homogeneous norm powers are
\(\|a_Ne_N\|_{\dot H^s}=cN^{s-\gamma}\). Thus
\(1/2<\gamma<3\) gives \(L^2\to0\),
\(\dot H^{1/2}\to0\), and \(\dot H^3\to\infty\). Every fixed
\(c>0\) enters any fixed positive critical radius for all sufficiently large
\(N\). At the
endpoint \(\gamma=1/2\), entry instead requires the prefactor, including the
chosen Fourier normalization, to lie below that radius.
**C,** The discrete linear heat baseline
\(H_{\rm disc}(\tau)=\max_{k\in\mathbb Z^3\setminus\{0\}}
|k|^3e^{-\tau|k|^2}\) is evaluated exactly on the plotted grid by exhaustive
enumeration of all three-square radii \(|k|^2\leq64^2\). For
\(\tau\geq10^{-3}\), the radial objective is decreasing beyond that cutoff,
so no omitted lattice vector can improve the maximum. The continuous radial
maximum is \((3/(2e\tau))^{3/2}\) and is therefore an upper bound. Panel C is
linear only; it is not a nonlinear entry certificate, a regularity theorem, or
evidence that the Navier--Stokes millennium problem has been solved.
