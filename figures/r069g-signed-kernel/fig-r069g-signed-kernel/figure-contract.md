# Figure contract — R0.69G signed-kernel robustness

## Question

Can sign changes of the vorticity-direction kernel provide a uniform annular
gain without controlling the nonnegative vorticity magnitude?

## Supported claim

For the two-lobe model, the uniform angular mean is zero while a magnitude
bias \(g_\eta=1+\eta\operatorname{sgn}D\) produces the exact positive response
\(\eta 2\sin(0.73)/(3\pi)\).  This is a visual instance of the proved duality
identity

\[
 \sup_{g\ge0,\int g=1}|\int Kg|=\|K\|_\infty.
\]

## Boundary

The figure does not show that arbitrary positive selectors are realizable as
smooth divergence-free vorticities.  It does not exclude estimates that
couple magnitude and direction, and it neither proves Navier-Stokes
regularity nor constructs a singularity.

## Non-color encoding

Negative contours are dashed, positive contours are solid, zero contours are
heavier, and each lobe carries an explicit sign.  The response panel uses a
solid exact curve and open certified markers.  These distinctions remain
visible in grayscale.
