# R0.71R certificate

This directory archives the exact and independent R0.71R audits.

- `result.json`: one-parameter source-power ledger, exact scaled NSE initial
  Fourier jet, even-touch homogeneity family, sequential polynomial family,
  and component-union family.
- `independent-result.json`: standalone Duhamel contraction sampling,
  homogeneity reconstruction, NSE frequency-jet scaling, Gauss--Legendre
  polynomial audit, and component-source audit.

The exact NSE calculation stops at the initial jet and first-jet parabolic
coefficient.  The remaining families are not Navier--Stokes trajectories.
The certificate supports a finite conditional theorem and a method
classification only.
