# R0.72R formal figure package

This package archives the journal figure for the explicit four-real-
dimensional caustic-free core beyond R0.72Q's \(Q_2\le1/2\) sufficient cone.

The plotted curves are direct samples of exact formulas.  They cannot replace
the continuous proof in `research/r072r_report-source.md`.  No PDE solve,
root fit, regression, or finite threshold inference is performed.

The formal build is fail closed.  It requires a clean source commit, the
sealed dual-route certificate in `research/certificates/r072r`, byte-stable
package sources, final-size and grayscale QA, and explicit visual inspection.
The public PDF, SVG, and 600 dpi PNG are byte-identical copies of the masters.

The result does not classify the complete four-dimensional caustic, prove
maximality of the core, cross a degenerate wall, or imply general
three-dimensional Navier--Stokes regularity.
