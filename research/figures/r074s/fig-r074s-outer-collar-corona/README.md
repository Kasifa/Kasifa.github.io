# R0.74S Step 14 formal analytic figure

This package contains the paper-ready analytic schematic for the outer-collar
coefficient alignment, density-threshold cancellation, and jump-corona
obstruction proved or isolated in R0.74S Step 14.

The figure is generated from exact rational formulas and frozen source hashes.
It is not a numerical Navier--Stokes experiment, simulation, or DNS result.

Run the commands in `command.txt`. The archival masters are `figure.svg`,
`figure.pdf`, and the 600 dpi `figure.png`. Visual QA derivatives and the
machine-readable validation report are included.
