平台时间内能量历史的准确代价

原 H 只需要末端平台 (I_R) 上的通量控制，Q/R 则采用更强的完整截止时间量词。把目标先限制到平台可以减弱辅助要求，但平台终点的阈值窗口仍可能跨入早期 cutoff 段；对真正位于平台内的窗口，过去能量必须由终点、总耗散、二次变差与负工作共同支付。

01 / 结论地图

减弱终点量词，不等于免费获得平台内历史

可减弱先为 H 的平台通量验证 tail 输入，无须先承担 Q 的全部早期终点。
仍分支终点虽在平台，原阈值窗口仍可能跨出平台；等号也必须单独处理。
准确代价扩大 cutoff 的反向历史包含 total dissipation、负工作与弱端点 BV 迹。

这项检查改变的是辅助路线的顺序：平台输入可以先做，但跨平台窗口、负工作目标级预算和耗散主导支路仍在。原 Clay B 的一般初值与指定中心要求没有减少。

02 / X.1–X.4

原 H 的平台目标弱于 Q/R 的全时间目标

对任意时间集合 Τ，逐点终端归约仍成立；它只用 (K=Q+F)、二次变差账本与有限例外壳上的 Cauchy–Schwarz，不要求 Τ 是完整截止区间。

C_R^M(Τ) ≤ C A_R + √N Z_R + S^K_{N,R}(Τ). (X.1–X.3) If the R.216–R.217 tail input is verified only at good τ in I_R, then C_R^M(I_R) ≤ C(A_R + Z_R). (X.4)

good-time 稠密性与 best-(N) 尾的下半连续性只把结论延拓到平台区间 (I_R)。X.4 足以服务原 H，却不证明 Q 的全时间增强目标；有符号累计通量不单调，较晚上界不能反推较早峰值。

03 / Y.1–Y.2

平台终点不保证原阈值窗口留在平台内

令 (t_p=t_0-R^2)。若平台段累计正工作不足 (E/4)，原 U 窗口必然跨过 (t_p)。若平台段达到阈值，可以重新选择一个平台内窗口 (J_k^P)，但必须保留等号情形：

G_k(τ−t_p) < E/4 → original threshold window crosses the ramp; G_k(τ−t_p) ≥ E/4 → select δ_k^P ≤ δ_k^F inside I_R. (Y.1–Y.2)

在等号时，平台前的零速率区间可能使原最大窗口更长，不能声称原窗口已完全位于平台。改选较短窗口后，((R^2/delta_k^P)^2) 可能更大，原逆宽度预算不能自动继承，R.217 必须针对所选平台窗重新证明。

04 / Y.3–Y.8

反向控制过去能量必须支付总耗散和负工作

为覆盖 W.7 的加厚质量域，引入新的空间 cutoff ξ_k，并保持原路径、原速度提升、常向量 a_R 与统一压力 gauge。由 defect-completed 局部能量等式，平台窗口 J=(a,τ) 内的历史成本是

H_k(J) = Ê_k(τ) + total-dissipation_k(J) + TV_J Q̂_k + ∫_J(F̂'_k)_−, M_k² ≤ (2R/γ_k) H_k(J). (Y.3–Y.8)

总耗散包含黏性耗散与 suitable 缺陷，并在反向历史中取正号；完整空间积分后的负工作也必须作为正成本保留。任意弱终点需要加权能量的左 BV 迹，不能用可能更小的物理端点值替换右侧，也不能把差额重新命名为端点 defect 原子。

05 / Y.9

代回局部耗散分支仍保留非正修正

在非余项分支中，以 (w=|J|/R^2) 和扩大历史 (H_k(J)) 代入 W.10，可得

d_k^vis ≥ c γ_k^(2/3) E_k(τ)^(4/3) H_k(J)^(−1) w^(−1/3) − 2w H_k(J). (Y.9)

γ_k^(2/3) 来自加权与未加权量的转换；末项是不可删除的 cutoff 修正，右端可能非正。该式没有把 H_k 或联合压力/中心漂移余项变成已知小量。

06 / Y.10–Y.12

正确几何给出 A+P，而不是目标 A+Z

加厚 (3R/4) 环壳仍至多重叠两次，外部只能由 (W_{2R}) 权重支付。重新运行二次、速度、压力和中心漂移的绝对账本后：

Σ_k TV Q̂_k ≤ C A_R, Σ_k TV F̂_k ≤ C P_R^M, Σ_k H_k(J_k) ≤ C(A_R + P_R^M). (Y.10–Y.12)

这里先逐壳用修改后的完整时钟，再求和；不同窗口的时间上确界没有与空间重叠错误交换。结果只恢复粗 (A+P) 层级：扩大时钟不是原 (K_k)，负变差不进入原 (Z_R)。它也只控制 η 加权时钟与平台窗口，未支付整个 (I_{2R}) 上未加权的 W.14。

02 / X.1–X.4

The original H plateau target is weaker than the Q/R all-time target

For any time set Τ, the pointwise terminal reduction remains valid. It uses only (K=Q+F), the quadratic-variation ledger, and Cauchy–Schwarz on finitely many exceptional shells; it does not require Τ to be the whole cutoff interval.

C_R^M(Τ) ≤ C A_R + √N Z_R + S^K_{N,R}(Τ). (X.1–X.3) If the R.216–R.217 tail input is verified only at good τ in I_R, then C_R^M(I_R) ≤ C(A_R + Z_R). (X.4)

Good-time density and lower semicontinuity of the best-(N) tail extend the result only through the plateau interval (I_R). X.4 is enough for the original H target, but it does not prove Q's strengthened all-time target. Signed cumulative flux is not monotone, so a later bound cannot recover an earlier peak.

03 / Y.1–Y.2

A plateau endpoint does not put the original threshold window inside the plateau

Let (t_p=t_0-R^2). If the positive work accumulated on the plateau is below (E/4), the original U window crosses (t_p). If the plateau reaches the threshold, one may select a new window (J_k^P) inside it, but the equality case must remain explicit.

G_k(τ−t_p) < E/4 → original threshold window crosses the ramp; G_k(τ−t_p) ≥ E/4 → select δ_k^P ≤ δ_k^F inside I_R. (Y.1–Y.2)

At equality, a zero-rate interval before the plateau may make the original maximal window longer. Hence the original window need not lie inside the plateau. A shorter selected window can increase ((R^2/delta_k^P)^2), so the old inverse-width budget is not inherited; R.217 must be reproved for the selected plateau windows.

04 / Y.3–Y.8

Backward control of past energy must pay total dissipation and negative work

A new spatial cutoff ξ_k covers the enlarged mass domain in W.7 while retaining the original path, lifted velocity, constant vector a_R, and common pressure gauge. The defect-completed local-energy equality gives the history cost on J=(a,τ):

H_k(J) = Ê_k(τ) + total-dissipation_k(J) + TV_J Q̂_k + ∫_J(F̂'_k)_−, M_k² ≤ (2R/γ_k) H_k(J). (Y.3–Y.8)

Total dissipation includes both viscous dissipation and the suitable defect, with a positive sign in the backward history; negative work after the full spatial integral is also a positive cost. An arbitrary weak endpoint requires the left BV trace of weighted energy. A possibly smaller physical endpoint value cannot replace that right-hand term, and the gap is not relabeled as an endpoint defect atom.

05 / Y.9

Substitution into the local-dissipation branch retains a nonpositive correction

In the non-remainder branch, substituting the enlarged history into W.10, with (w=|J|/R^2), yields

d_k^vis ≥ c γ_k^(2/3) E_k(τ)^(4/3) H_k(J)^(−1) w^(−1/3) − 2w H_k(J). (Y.9)

The power γ_k^(2/3) comes from converting between weighted and unweighted quantities. The last term is a cutoff correction that cannot be removed, and the right-hand side may be nonpositive. The formula does not make H_k, or the joint pressure/centre-drift remainder, a known small quantity.

06 / Y.10–Y.12

The correct geometry yields A+P, not the target A+Z

The (3R/4)-padded annuli still overlap at most twice, and their exterior is paid only by the (W_{2R}) weight. Re-running the quadratic, velocity, pressure, and centre-drift absolute ledgers gives

Σ_k TV Q̂_k ≤ C A_R, Σ_k TV F̂_k ≤ C P_R^M, Σ_k H_k(J_k) ≤ C(A_R + P_R^M). (Y.10–Y.12)

Each shell first uses its modified complete clock, and only then are shells summed; the time suprema of different windows are not exchanged with spatial overlap. This recovers only the coarse A+P level. The enlarged clock is not the original (K_k), and its negative variation is not part of the original (Z_R). The result also controls only η-weighted clocks and plateau windows, not the unweighted W.14 over the full (I_{2R}).
