# R0.71O journal figure package

This package archives the finite-order soft-denominator profiles, their
one-sided signed and Jordan face measures, the oscillatory Hilbert-path
separation from ordinary quadratic budgets, and one genuine smooth NSE
initial entry face used in R0.71O.

Panel A shows exact normalized inner profiles for an odd first-order zero and
an even second-order zero. Panel B distinguishes the signed derivative atom
and standard hard-BV jump from the relaxed/Jordan face cost. Panel C is an
abstract smooth Hilbert-path family: its soft face variation grows like
`2 N` while denominator mass vanishes and first-time-derivative mass remains
fixed. Panel D reconstructs four exact target Fourier modes of one smooth NSE
initial jet and the right entry trace `a(0+)=1/4`.

The package contains 178 mm vector PDF and SVG exports, a 600 dpi PNG,
self-contained exact and independent certificates, machine-readable plotted
data, producer and independent validators, color and true-grayscale QA
previews, a visual QA report, environment details, a manifest, and SHA-256
hashes.

Panel C is not constrained to be a coupled NSE observable. Panel D is a
one-sided initial-jet calculation, not a time step, internal-face construction,
unbounded NSE face-count theorem, or failure of an NSE face estimate. No DNS,
continuation criterion, singularity, regularity, originality, or
Millennium-problem conclusion is represented.
