00 / Boundary

严格部分是约化，开放部分是衰减

PROVED四通道尺度

尖锐—尖锐、两个混合通道、纵向—纵向分别为 \(N^2,N,N,1\)。

PROVED条件一致上界

两个生成尖锐坐标若为 \(O(N^{-1})\)，则 \(G_N=O(1)\)。

COMPUTED\(N=4,5\) 高精度探针

两套 MPFR 精度一致，并回归到 R0.24 的精确点。

OPEN全 \(N\) 尖锐坐标衰减

当前递推还没有给出所需的带符号分母下界。

准确边界。通道分解和条件不等式是一般 \(N\ge2\) 的代数结论。\(N=4,5\) 只是高精度有限计算。这里没有得到所有 \(N\) 的增益上界，也没有证明三维 Navier–Stokes 的全局正则性或有限时奇性。
01 / Catalyst parity

每个边界标签只占二次域的一条有理线

边界面的两个泵叶是 \((1,-1,1),(-1,-1,-1)\)，两个催化叶是 \((1,-1,-1),(-1,-1,1)\)。若催化叶总数为 \(C\)，标签为 \(m=(m_1,-L,m_3)\)，则

\[C\equiv \frac{m_1-m_3}{2}\pmod 2.\]

催化叶各带一个 \(t\)，而 \(t^2\in\mathbb Q\)。因此同一标签的所有树历史都落在 \(\mathbb Q\) 或 \(t\mathbb Q\) 的同一条线上。\(a_N,b_N,a_N+b_N\) 的奇偶分别是 \(N-1,N,1\)。这解释了精确检查点中的交替结构，但奇偶性本身不会抑制尖锐方向。

02 / Decomposition

横向余弦不是需要控制的量

带电锥模态满足 \(q_m\ell+\beta_m\cdot w=0\)，范数取 \(M(w,\ell)=|w|+|\ell|\)。定义单位尖锐模态 \(S_m\) 和单位纵向模态 \(L_m\)：

\[S_m=\left(\frac{d\times\beta_m}{\sqrt3|\beta_m|},0\right),\qquad L_m=\left(\frac{\beta_m}{|\beta_m|(1+6|\beta_m|)},-\frac{6|\beta_m|}{1+6|\beta_m|}\right).\]

每个归一化系数唯一写成

\[\frac{U(m)}{M(U(m))}=\sigma_mS_m+\lambda_mL_m.\]

\(\sigma_m\) 才是进入二次障碍的尖锐坐标。一个模式的横向部分可以与尖锐方向高度对齐，但只要完整范数由纵向 jet 主导，\(\sigma_m\) 仍然很小。对当前两个输入，\(|\lambda_m|\le25/24\)。

03 / Channel inequality

唯一的 \(N^2\) 项是 \(\sigma_A\sigma_B\)

R0.22 标签的偏移满足

\[|\beta_A|^2=6N^2-2N+\frac23,\quad |\beta_B|^2=6N^2-4N+\frac23,\quad \beta_B\cdot(d\times\beta_A)=-(3N-1)^2.\]
单位输入通道精确渐近尺度\(N\ge2\) 的简明上界
\(S_A,S_B\)\(27N^2+o(N^2)\)\(44N^2\)
\(S_A,L_B\)\(\frac{3}{2\sqrt2}N+o(N)\)\(7N\)
\(L_A,S_B\)\(\frac{3}{2\sqrt2}N+o(N)\)\(7N\)
\(L_A,L_B\)\(\frac18+o(1)\)1
条件上界。
\[G_N\le44N^2|\sigma_A\sigma_B|+7N\bigl(|\sigma_A\lambda_B|+|\lambda_A\sigma_B|\bigr)+|\lambda_A\lambda_B|.\]

所以 \(|\sigma_A|\le C_A/N\)、\(|\sigma_B|\le C_B/N\) 足以推出 \(G_N=O(1)\)。这把缺失的机制精确缩减为两个归一化尖锐坐标的衰减。

05 / Root splits

递推由边缘项主导，但依赖带符号抵消

对 \(a_N\)，最大的分组根项总是右侧只有一个叶子；对 \(b_N\)，则是左侧只有一个叶子。

\(N\)\(a_N\) 主导分裂 / 完整系数\(b_N\) 主导分裂 / 完整系数四通道实际和 / 范数和
2\(5+1\) / 0.4156\(1+4\) / 0.63170.7575
3\(8+1\) / 1.0379\(1+7\) / 0.65790.4372
4\(11+1\) / 0.9860\(1+10\) / 0.72260.7631
5\(14+1\) / 1.2565\(1+13\) / 0.78790.4272

分裂比可以超过一，因为其他根分裂会反向抵消。普通正值主控量能够给尖锐分子做上界，却不能给完整系数提供所需的带符号下界。这是目前无法证明 \(\sigma=O(N^{-1})\) 的具体位置。

06 / Next

下一步是三叶传递系统，不是继续列数据点

\[a_{N+1}-a_N=(1,-3,3),\qquad b_{N+1}-b_N=(-1,-3,-3).\]

参数每增加一，两个端点族都只增加三个边界叶。结合一叶根分裂占主导和催化奇偶翻转，下一项 R0.26 将构造带两态奇偶的三叶传递系统。

  1. 把一叶附着项写成有限维传递矩阵。
  2. 在 \(N\sigma\) 归一化下估计其谱半径。
  3. 把其余根分裂作为带符号余项，而不是逐项取绝对值。
  4. 若余项不能收缩，就定位第一个非收缩伴随标签族。
