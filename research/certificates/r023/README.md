# R0.23 generated-subspace certificate

This directory archives the exact first-encounter audit for the R0.22 sharp
label family inside the Taylor field generated by the optimized R0.20 datum.

## Contents

- generated-subspace-sharpness.json: exact quadratic-field coordinates,
  support counts through time order ten, the \(N=2\) sharp-label records,
  operator-gain comparisons, and finite-shell convergence checks.
- SHA256SUMS: checksums for this README and the JSON certificate.

## Main certified statements

At the rational center of the R0.20 root certificate:

1. The labels \(a=(2,-6,4)\), \(b=(-1,-5,-5)\), and
   \(a+b=(1,-11,-1)\) occur at their minimal Taylor orders \(5,4,10\).
2. The generated input coefficients have exactly nonzero projections on the
   two R0.22 sharp transverse directions.
3. Both longitudinal cone jets are exactly nonzero.
4. The two ordered root interactions do not cancel exactly.
5. The actual normalized symmetrized gain is
   \(0.3045602145876\ldots\), or \(0.00433464080384\ldots\) of the
   R0.22 sharp-polarization gain at the same labels.
6. This root split contributes about \(4.57\times10^{-4}\) of the complete
   order-ten output mode norm.

These statements are exact only at the recorded rational root center.  The
decimal comparisons are real embeddings of exact elements \(A+Bt\).  The
certificate does not give a uniform root-box or all-\(N\) result.

## Reproduction

The JSON was generated from clean source commit d23858a with:

    PYTHONPATH=research python3.12 \
      research/generated_subspace_sharpness_audit.py \
      --check --pretty --progress \
      --output research/certificates/r023/generated-subspace-sharpness.json

Verify the archive with:

    cd research/certificates/r023
    shasum -a 256 -c SHA256SUMS
