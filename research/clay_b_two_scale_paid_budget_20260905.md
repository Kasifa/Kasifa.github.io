## 1. 固定平滑尺度可以越过弱解时间端点

设 u 是 [0,T] 上周期、无外力、黏性 1 的 Leray--Hopf 解，
取其弱连续 L^2 代表；压力取空间均值为零的周期代表。
固定任意 rho>0。以下常数允许依赖 rho，不对 rho->0 一致。

令 P 为周期 Leray 投影。空间卷积后的分布方程为

\[
 \partial_t b_\rho
 =\Delta b_\rho-\mathbb P\,\nabla\cdot S_\rho(u\otimes u),
 \qquad b_\rho=S_\rho u.
\tag{E.1}
\]

对任意非负整数 m，P div S_rho 的周期卷积核是 C^infty：
其非零 Fourier 乘子为多项式增长的 Leray 乘子乘以 phi_hat(rho k)，
后者快速衰减。零模态的导数为零。故若
K=ess sup_[0,T] ||u(t)||_2，则

\[
 \|\partial_t b_\rho\|_{L^\infty_t C^m_x}
 \le C_{\rho,m}(K+K^2),\qquad
 b_\rho\in W^{1,\infty}([0,T];C^m).
\tag{E.2}
\]

这里使用 ||u tensor u||_1<=K^2 和平滑核的上确界，
以及 Delta S_rho 从 L^2 到 C^m 的有界性。
也可先在每个 Fourier 模态积分 (E.1)，再由核界重建该代表。
S_rho 从 L^2 到每个固定 C^m 是紧算子，故 u 的弱连续性经它
变为强连续性，保证该代表正是每个时刻的 S_rho u，而非另外选择的时间迹。
相同的平滑核论证给 p_rho=S_rho p 的空间各阶界。

固定 R 的路径 X_R'=b_R(t,X_R) 因此在闭时间区间上良定义，
且给定终点后唯一。对固定 r、R，g=b_r-b_R 具有上述时间正则性。
将两条滤波方程相减并逐项积分，D.5 的恒等式几乎处处成立，
其时间积分在任意两个闭区间端点均成立。

这不是原始弱解 u 的能量等式，也没有证明其局部 defect 为零：
原始非线性都保留在 tau_rho 中。这里只对固定正尺度的光滑
卷积场作能量配对。固定尺度性质不能在没有统一界时令 R->0，
亦不把 P 已有的固定尺度弱稳定性重新标成 OPEN。

## 2. 精确几何与待支付量

固定 theta in (0,1)、r=theta R，并取
0<R<min(pi/16,sqrt(t_0)/8)。记

\[
 J=(t_0-64R^2,t_0),\quad J_1=(t_0-R^2,t_0),\quad
 Q_c=\{(t,x):t\in J,\ |x-X_R(t)|<cR\}.
\tag{E.3}
\]

球距离在周期域使用唯一的局部提升；3R<pi。
所有体积分沿同一 X_R，未将 X_r 的管道当作 X_R 的管道。
以下用普通 Lebesgue 积分，D 稿的归一化常数相消。
对任意使下式有限的时间 gauge c(t)，定义

\[
 A_2=R^{-3}\int_{Q_3}|u|^2,\quad
 C_3=R^{-2}\int_{Q_3}|u|^3,\quad
 D_{3/2}=R^{-2}\int_{Q_3}|p-c(t)|^{3/2}.
\tag{E.4}
\]

对 Leray--Hopf 解，这些量在固定正 R 时有限：
能量插值给 u in L^{10/3}_{t,x}，压力公式与 Riesz 变换给
p in L^{5/3}_{t,x}，可取 c=0。这里不由有限性推出随尺度小性。

取 0<=psi<=1，psi=1 于 B_1，支撑于 B_2，空间各阶导数固定。
令 chi(t,x)=eta(t)psi((x-X_R(t))/R)，其中 eta 在 J 左端为零，
在 J_1 上恒 1，且 0<=eta<=1、|eta'|<=C/R^2。
这一构造保留了时间截止支付，不删除早期时间段。

**命题（有完整支付的固定尺度估计）。**

\[
\begin{aligned}
 \mathscr D_{r,R}:={}&
 R^{-1}\sup_{t\in J_1}\int_{B_R(X_R(t))}|g(t)|^2\\
 &+R^{-1}\int_{J_1}\int_{B_R(X_R(t))}|\nabla g|^2\\
 \le{}& C_{\theta,\varphi,\psi}(A_2+C_3+D_{3/2}).
\end{aligned}
\tag{E.5}
\]

常数独立于解、t_0、R 和压力 gauge。theta 固定，不声称 theta->0
一致；该命题没有给出小于 1 的收缩系数。

## 3. 逐项证明

在每个固定时间，以 V=B_{2R}(X_R(t))、W=B_{3R}(X_R(t)) 记球。
卷积核的支撑和局部 Young 不等式给，1<=q<=infty，

\[
 \|b_\rho\|_{L^q(V)}
  +R\|\nabla b_\rho\|_{L^q(V)}
 \le C_{\theta,\varphi}\|u\|_{L^q(W)}
 \quad(\rho=r,R).
\tag{E.6}
\]

证明时可将 u 在 W 外截为零：V 中的卷积只取 W 内值；
对梯度改用 grad phi_rho，其 L^1 范数为 C/rho。
相同界适用于 g。应力和压力则满足

\[
 \|\delta\tau\|_{L^{3/2}(V)}
 \le C_\varphi\|u\|_{L^3(W)}^2,\quad
 \|\delta p\|_{L^{3/2}(V)}
 \le C_\varphi\|p-c(t)\|_{L^{3/2}(W)}.
\tag{E.7}
\]

第二式用 S_r c=S_R c=c，第一式对每个卷积乘积应用 Young 和 Holder。
沿路径的速度不是体积平均的自由替代量；它另有点值估计

\[
 |a_R(t)|=|b_R(t,X_R(t))|
 \le C_\varphi R^{-1}\|u(t)\|_{L^3(W)}.
\tag{E.8}
\]

这是 phi_R 的 L^{3/2} 核范数 C R^{-1} 与 Holder，
不是对原始 u 的路径迹估计。
再用 ||g||_{L^2(V)}^2<=C R||g||_{L^3(V)}^2，得到

\[
 |a_R|\int_V|g|^2
 \le C\|u\|_{L^3(W)}^3.
\tag{E.9}
\]

代入 D.5--D.6，其右端各项的绝对值分别有以下完整控制：

| 项 | 每个时刻的上界 |
|---|---|
| eta' 和 Delta chi 的二次项 | C R^{-2} int_W \|u\|^2 |
| (b_R-a_R) dot grad chi 的残余漂移 | C R^{-1} int_W \|u\|^3 |
| chi g_i g_j partial_j b_{r,i} | C R^{-1} int_W \|u\|^3 |
| delta tau : chi grad g | C R^{-1} int_W \|u\|^3 |
| delta tau : (g tensor grad chi) | C R^{-1} int_W \|u\|^3 |
| delta p g dot grad chi | C R^{-1} (int_W \|p-c\|^{3/2} + int_W \|u\|^3) |

残余漂移的 a_R 部分用 (E.9)，b_R 部分用三个 L^3 因子的 Holder。
拉伸项用 (E.6) 的导数界；两个应力项用 (E.6)--(E.7)。
压力项先得到
C R^{-1} ||p-c||_{3/2}||u||_3，再用 Young，指数分别为 3/2 与 3。
没有把压力或应力称为具有有利符号。

从 J 左端积分至任意 t in J_1。初始 chi=0，右侧均可延长为 J
的非负上界。再分别取末端能量的上确界与最终时刻的耗散界，
利用 chi=1 于 J_1 内的 B_R，最后除以 R，得到 (E.5)。
第 1 节使同一证明适用于固定尺度的 Leray--Hopf 解，
不需假设原始解在 t_0 光滑，也不需选有利的硬时间截面。

## 4. 为什么这还不是主合同所需的估计

移动管 Q_3 的体积为常数乘 R^5。Holder 直接给

\[
 A_2\le C C_3^{2/3},\qquad
 \mathscr D_{r,R}\le C_\theta(C_3^{2/3}+C_3+D_{3/2}).
\tag{E.10}
\]

所有量是 NS 抛物缩放下无量纲的。这是合理的支付形式，但右侧
没有由任意初值推出的小性或同一候选中心的尺度可求和性。
假设其右侧趋零不等于证明该趋零。

还须区分三个不同对象：

- (E.5) 控制固定 X_R 周围的滤波场差 g，不是未滤波速度的 E_R；
- g 的体积能量不是它沿 X_r 或 X_R 的迹，不能直接改善路径预检；
- 固定 r/R 下的估计不提供 E_{r}<=lambda E_R+e_R 的 lambda<1。

压力 gauge 消除了任意时间常数，但没有消除外部压力的非局部输入。
若要以速度控制 D_{3/2}，仍须做带尾项的局部/调和压力分解。

原始 NS 的局部乘积输运用于 D.3 和 (E.6)--(E.9) 的局部化；
一般 averaged NS 双线性项没有理由享有完全相同的局部恒等式。
但本稿并未得到排除奇点的正向预算，不能把这一区别称为已经
克服 averaged-NS 障碍。任何后续正向论证仍需逐步检查其区分力。
