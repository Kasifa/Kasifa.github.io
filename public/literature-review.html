三维 Navier–Stokes
全局正则性问题

这页只回答三个问题：目前已经证明了什么，哪些爆破图景已经排除，我的研究路线和现有文献在哪里相接。定理、预印本和本站笔记分开记录。

当前结论 问题仍未解决

现有理论对潜在奇性已经给出不少限制，但还不能从能量估计得到一般大数据所需的全局临界控制。

笔记 01 / 问题边界

先把问题说清楚

这里问的不是“有没有某种解”，而是光滑三维解能否在有限时间失去正则性。

\[ \partial_t u+(u\cdot\nabla)u-\Delta u+\nabla p=0, \qquad \nabla\cdot u=0, \qquad u(\cdot,0)=u_0. \]

Clay 的正式表述允许两类答案：证明所有允许的光滑初值都产生全局光滑解，或构造一个满足正式条件的有限时破裂。本站先看无外力、任意光滑无散初值的全局正则性。二维结果、修改方程、特殊对称解和带外力弱解非唯一性，都不能回答这个问题。[1][2]

这页怎样使用证据

我把已发表定理列为已知结果，2026 年预印本单独标记，本站 R0.69P–R0.71R 只列为研究笔记。我不把计算或笔记外推成正则性定理。

笔记 02 / 临界尺度

困难出现在临界尺度

能量估计可以一直成立，但它没有排除能量向越来越小的尺度集中。三维涡量拉伸正好作用在这里。

\[ u_\lambda(x,t)=\lambda u(\lambda x,\lambda^2t), \qquad p_\lambda(x,t)=\lambda^2p(\lambda x,\lambda^2t), \] \[ \frac12\frac{d}{dt}\|\omega\|_2^2+\|\nabla\omega\|_2^2 =\int_{\mathbb R^3}\omega\cdot S\omega\,dx. \]

速度空间 \(L^3\)、\(\dot H^{1/2}\)、\(BMO^{-1}\) 和一些临界 Besov 范数都与方程缩放相容。小临界数据有全局理论，大临界数据有局部理论；如果潜在爆破前 \(L_t^\infty L_x^3\) 一直有界，爆破就不会发生。缺口很具体：能不能只从一般大数据已有的能量级信息，推出一个全局临界界。[5][6][7][8][10]

笔记 03 / 文献地图

五条主要理论分支

我把常用结果分成五支。它们不是五个互相竞争的解法，而是从不同方向限制潜在奇性。

条件正则性

Serrin 与端点 \(L^3\)

若 \(u\in L_t^qL_x^p\)、\(2/q+3/p\le1\)，则相应区间正则；ESS 封闭了 \(p=3,q=\infty\) 端点。条件本身尚未由能量自动推出。[4][10]

部分正则性

CKN 与 \(\varepsilon\)-正则性

适合弱解的奇异集具有零的一维抛物 Hausdorff 测度。潜在奇性很稀疏，但“稀疏”仍不等于“空集”。[11]

临界元

浓缩紧性与刚性

若临界空间中存在爆破数据，可以尝试抽取最小爆破元，再用紧性和唯一延拓排除；框架仍需要临界范数先验有界。[12][18]

几何耗散

涡量方向与中间应变特征值

方向相干或 \(\lambda_2^+\) 的临界控制足以得到正则性；目前它们仍是条件判据，不是一般解自动满足的结论。[19][20][21][22]

笔记 04 / 已知结果

经典理论骨架

先把存在、唯一和正则分开，才不会把弱解存在误写成全局正则性结论。

理论层级已经严格得到仍然缺少
Leray–Hopf全局有限能量弱解存在。[3][4]一般唯一性与全局光滑性。
临界局部理论临界空间局部解，小数据全局解。[5][6][7]任意大数据的全局临界界。
Serrin / ESS临界时空量有界则不爆破。[4][10]从能量自动推出临界量有界。
CKN奇异集极小，局部小量触发正则。[11]证明奇异集为空。
自相似排除排除一类经典后向固定剖面。[24][25]排除 Type II、形状变化和多尺度递归爆破。
几何耗散方向相干或应变特征值控制足以正则。无条件产生这些几何控制。
定量正则性爆破下界、浓缩尺度和奇点数控制。[13][14]把必要浓缩变成矛盾。
弱非唯一性较弱解类或带外力 Leray 解可非唯一。[27][28]这些结果不等价于无外力光滑初值的 Clay 核心问题。
笔记 05 / 爆破边界

哪些爆破图景已被排除

下面只区分三件事：已经排除、受到定量约束、仍然开放。

Seregin 证明，若真有潜在爆破，则 \(\|u(t)\|_3\to\infty\)。Tao 给出端点正则性的定量高阶界和爆破下界。Barker–Prange 把 Type I 上界与空间浓缩、临界范数下界和奇点数量联系起来。它们说明了爆破必须满足什么，但还没有推出矛盾。[13][14][23]

笔记 06 / 近期论文

2019—2026 年值得保留的进展

这里只保留改变理论边界的结果。我不判断离最终解还有多远，因为目前没有可检验的标准。

定量正则性

临界正则性的定量化

Tao 给出临界 \(L^3\) 控制下的显式高阶界和爆破下界；Barker–Prange 进一步连接 Type I 图景、局部浓缩和奇点数量。[13][14]

部分正则性

CKN 的对数改进

Lei–Ren 对部分正则性作定量改进，并得到轴对称小旋量情形的应用；一般三维奇异集仍未证明为空。[15]

临界端点

Lorentz 与应变特征值条件

近年的工作把定量边界推进到临界 Lorentz 空间，并细化中间应变特征值的延拓条件；这些仍是条件正则性结果。[16][17]

三篇与当前路线相邻的 2026 年预印本

Yu 的一篇工作讨论过滤后的涡量拉伸、增量缺陷、远场应变和局部化余项；另一篇 moving-window defect-cascade 工作把 pressure、flux、energy、trace 和 Carleson packing 放进条件框架，但把真正的 NSE depletion 与窗口闭合保留为分析输入。Grujić 在给定临界浓缩与加权 BMO 涡量方向条件下得到对数耗散机制。它们都接近本站的“增量—尺度—局部预算”路线，但截至资料截止日仍是预印本，也都不是一般大数据全局正则定理。[29][31][30]

不能误读的两类结果

Tao 的平均 Navier–Stokes 模型爆破说明能量与缩放等粗结构不足以单独完成证明，但不是原方程的反例。Buckmaster–Vicol 与 Albritton–Brué–Colombo 的弱非唯一性定理有解类或外力边界，也不能替代无外力光滑初值的 Clay 核心问题。[26][27][28]

笔记 07 / 当前路线

本站路线在文献图上的位置

这张本站路线图从 R0.69P 开始；R0.61–R0.69O 的历史节点没有删除，全部保留在 累计回顾与 82 节索引中。R0.69P–R0.71P 走到 positive-entry temporal-packing boundary，R0.71Q 隔离 analytic/Jensen 四税；R0.71R 再证明 finite conditional parabolic-incidence theorem，并为 certificate (3.3) 定位 rho=0 scale covariance 与 rho=2 minimal Leray payment 的两阶错配。保留下来的结果都不是全局正则性结论。

R0.71R 关闭了什么，R0.71S 只检查什么

R0.71R 从 localized observable 的 exact forced heat equation 出发，证明 finite conditional packing theorem。uniform 0<theta_-<=theta_beta<=theta_* 与 forward-window availability 是 theorem gates，不是右端因子；Gamma_rho 是 upper comparison constant，1/Gamma_rho 编码 lower-charge strength，M 是 essential same-observable overlap。rho=2 是 normalized zero-mean torus 上的 minimal Leray-paid index：Leray energy 支付 source integral，frame constants 由固定 frame 给定；完整右端仍可能因 Gamma_2 与 M 而不一致。对对应 finite covariant event/window family，Gamma_rho^opt 定义为 least admissible upper comparison constant；固定 torus 上 compatible integer/dyadic dilation 必须协变搬运 multiplier、cutoff、event 与 window，且只有 Gamma_rho^opt 按 lambda^rho 缩放。整数 Fourier example 只定义 Gamma_{2,jet}=K^2/(4 theta^2) surrogate，不给 positive-time upper comparison constant Gamma_2 下界。certificate (3.3) 以外的 Duhamel designs 保持开放；R0.71S 只检查 signed / bilinear scale-critical packet。我继续用下面六条筛选。

R0.71R 的一手文献边界

Caffarelli–Kohn–Nirenberg与Lei–Ren为 singularity / regularity cylinders 给 local-energy gate，不给 smooth filtered entry 的 lower charge。Koch–Tataru给 parabolic square-Carleson upper norm；Angenent的一维标量齐次 spatial zero-number law 还要求 uniform parabolicity、coefficient regularity、相应 boundary hypotheses 与 positive time。两者都不直接控制三维 Hilbert-valued forced observable 的 temporal entries。两轮限定检索未找到 uniform R0.71R incidence / overlap theorem；这是 bounded negative finding，不是原创性、优先权或不存在性结论。

  1. 尺度正确。在 Navier–Stokes 缩放下临界或略次临界。
  2. 能量级可定义。适合弱解上有意义，不预先要求高阶光滑性。
  3. 保留符号。关键步骤不能过早取绝对值。
  4. 全空间结算。近场、远场、交换子和局部化边界都要纳入。
  5. 动态可迭代。沿时间或半径产生严格收缩，而非静态重写。
  6. 不循环论证。不能把想证明的临界控制重新当作假设。

数值计算只用来找候选结构和反例，不承担证明。通过计算筛选后，还需要区间或精确证书、分析引理，以及与弱解或临界空间的严格接口。
