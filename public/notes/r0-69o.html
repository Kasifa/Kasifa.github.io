00 / Main result

领先压力交换子的时间余项可以降回二次涡量

沿用 R0.69N 的紧支撑无散局部化 \(v\)，定义

\[ \mu_v=r^{-1/2}\|v\|_2,\qquad \sigma_v=r^{1/2}\|\nabla v\|_2,\qquad \mathcal D_v=r^3\|\nabla^2v\|_2^2. \]

截断环带 \(A_\phi\subset B_r\) 位于 \(v=u\) 的区域，因此 \(D_A\le\mathcal D_v\)。R0.69N 的领先压力项由下式控制：

\[ \boxed{ \mu_v^{1/2}\sigma_v^{3/2}\mathcal D_v^{1/2} \le\varepsilon\mathcal D_v +C\varepsilon^{-3}\mu_v^4\sigma_v^2.} \]

在长度为一的归一化时间区间 \(I\) 上，令

\[ \mathsf A_v=\|\mu_v\|_{L^\infty_\tau(I)}^2,\qquad \mathsf E_v=\int_I\sigma_v^2\,d\tau,\qquad \mathsf F_v=\int_I\mathcal D_v\,d\tau. \]

时间积分后得到

\[ \boxed{ \int_I\mu_v^{1/2}\sigma_v^{3/2}\mathcal D_v^{1/2}\,d\tau \le\varepsilon\mathsf F_v +C\varepsilon^{-3}\mathsf A_v^2\mathsf E_v.} \]
严格边界。 这条估计修复了领先压力交换子的时间指数。它尚未推导完整的局部 \(H^1\) 不等式，也没有推出全局正则性、奇性或千禧年问题的结论。
01 / Hilbert interpolation

可吸收二阶导数同时提供缺失的空间插值

由于 \(v\) 紧支撑，分部积分与 Cauchy–Schwarz 给出

\[ \|\nabla v\|_2^2 =-\int v\cdot\Delta v\,dx \le\|v\|_2\|\Delta v\|_2 \le C\|v\|_2\|\nabla^2v\|_2. \]

乘以 \(r\) 后恰好成为尺度不变关系

\[ \boxed{\sigma_v^2\le C\mu_v\mathcal D_v^{1/2}.} \]

对集中在波数 \(k\) 的 Fourier 波包，\(\|\nabla v\|_2\asymp k\|v\|_2\)、\(\|\nabla^2v\|_2\asymp k^2\|v\|_2\)，所以该插值在频率幂上不能改进。

02 / Double Young reduction

关键不是再做时间 Hölder，而是把耗散使用两次

简写 \(\mu=\mu_v\)、\(\sigma=\sigma_v\)、\(\mathcal D=\mathcal D_v\)。第一次 Young 不等式给出

\[ \mu^{1/2}\sigma^{3/2}\mathcal D^{1/2} \le\delta\mathcal D+C\delta^{-1}\mu\sigma^3. \]

不立即对 \(\mu\sigma^3\) 作时间估计，而是使用上一节的插值：

\[ \mu\sigma^3 =\mu\sigma\,\sigma^2 \le C\mu^2\sigma\mathcal D^{1/2}. \]

第二次 Young 不等式于是得到

\[ C\delta^{-1}\mu^2\sigma\mathcal D^{1/2} \le\delta\mathcal D+C\delta^{-3}\mu^4\sigma^2. \]

合并并把 \(2\delta\) 重命名为 \(\varepsilon\)，即得主结果。二阶导数既作为被吸收项出现，又通过 Hilbert 插值降低余项的 \(\sigma\) 次数；这正是纯时间不等式遗漏的信息。

03 / Algebraic sharpness

仅使用这条插值时，\(\mu^4\varepsilon^{-3}\) 是必要代价

令插值取等并参数化为

\[ \sigma=\mu z,\qquad \mathcal D=\mu^2z^4. \]

若希望右端为 \(\varepsilon\mathcal D+C_\varepsilon\mu^\alpha\sigma^2\)，除以 \(\mu^2z^2\) 后必须控制

\[ \mu z^{3/2}-\varepsilon z^2. \]

其极大点与极大值分别为

\[ \boxed{ z_*=\left(\frac{3\mu}{4\varepsilon}\right)^2,\qquad \max_{z>0}\bigl(\mu z^{3/2}-\varepsilon z^2\bigr) =\frac{27}{256}\varepsilon^{-3}\mu^4.} \]

因此在这个纯代数机制内必须有 \(\alpha\ge4\)，临界情形的 \(\varepsilon^{-3}\) 也不能降低。这里的尖锐性不声称真实 Navier–Stokes 压力场同时饱和前面每一步。

04 / Spike replay

旧时间尖峰不再是否定见证，因为它必须支付发散耗散

R0.69N 的归一化尖峰为

\[ \mu_A(\tau)=1,\qquad \sigma_A(\tau)=A\mathbf1_{[0,A^{-2}]}(\tau). \]

它确实满足

\[ \int\sigma_A^2\,d\tau=1,\qquad \int\mu_A\sigma_A^3\,d\tau=A. \]

但一旦强制 Hilbert 插值，尖峰区间上就有

\[ \mathcal D_A\ge c\frac{\sigma_A^4}{\mu_A^2}=cA^4. \]

于是

\[ \boxed{\int\mathcal D_A\,d\tau\ge cA^2\longrightarrow\infty.} \]

它仍然否定只从 \(\int\sigma^2\) 出发的纯时间闭合，却不能否定允许吸收二阶耗散的估计。

05 / Enlarged-ball localization

抽象的 \(\mathcal D_v\) 可还原为扩大球耗散与显式截断代价

R0.69N 使用 \(v=\eta u-w\)，其中 \(\nabla\cdot w=\nabla\eta\cdot u\)。Bogovskii 算子的高阶 Sobolev 映射性质给出

\[ \|\nabla^2w\|_2\le C\left( r^{-1}\|\nabla u\|_{L^2(A_\eta)} +r^{-2}\|u\|_{L^2(A_\eta)}\right). \]

结合 \(\nabla^2(\eta u)\) 的乘积法则，得到

\[ \boxed{ \mathcal D_v^{1/2} \le C\left(D_{3r}^{1/2}+\sigma_{A_\eta}+\mu_{A_\eta}\right), \qquad D_{3r}=r^3\|\nabla^2u\|_{L^2(B_{3r})}^2.} \]

因此

\[ \varepsilon\mathcal D_v \le C\varepsilon D_{3r} +C\varepsilon(\sigma_{A_\eta}^2+\mu_{A_\eta}^2). \]

这只进行一次半径扩大，但后续完整局部估计仍必须执行半径迭代并追踪局部化产生的全部方程；本页没有省略这一接口。

06 / Lower commutator terms

两个低阶项成为有限动能幂，而不是新的临界耗散

使用 \(\sigma\le C\mu^{1/2}\mathcal D^{1/4}\)，R0.69N 的其余近场项满足

\[ \begin{aligned} \mu^{1/2}\sigma^{5/2} &\le\varepsilon\mathcal D +C\varepsilon^{-5/3}\mu^{14/3},\\ \mu^{3/2}\sigma^{3/2} &\le\varepsilon\mathcal D +C\varepsilon^{-3/5}\mu^{18/5}. \end{aligned} \]

在单位归一化时间区间，它们分别只贡献 \(\mathsf A_v^{7/3}\) 与 \(\mathsf A_v^{9/5}\)。这些是 Caccioppoli 型截断代价，不会重新引入三次涡量时间积分。

07 / Transition and remote field

过渡应力与远程壳层仍停留在二次时间预算内

R0.69N 的外部压力预算保持为

\[ r^3|\mathcal P_{\mathrm{ext}}| \le C\sigma_r(e_{\mathrm{tr}}+B_\infty). \]

令 \(\mathsf H=\|e_{\mathrm{tr}}+B_\infty\|_{L^\infty_\tau(I)}\)，Cauchy 与 Young 给出

\[ \int_Ir^3|\mathcal P_{\mathrm{ext}}|\,d\tau \le C\mathsf H\mathsf E_r^{1/2} \le\delta\mathsf E_r+C\delta^{-1}\mathsf H^2. \]

R0.69M 的远场增益 \(B_\infty\le\mathfrak M_2/120\) 没有损失；压力近场、过渡区与远场现在都具有明确的二次时间接口。

08 / Pressure-sector budget

时间积分后的压力预算已不再含三次涡量余项

把领先项、低阶交换子项与外部压力合并，得到示意性的压力扇区估计

\[ \begin{aligned} \int_Ir^3|\mathcal P_r|\,d\tau \le{}&\varepsilon\mathsf F_v +C\varepsilon^{-3}\mathsf A_v^2\mathsf E_v\\ &+C_\varepsilon(\mathsf A_v^{7/3}+\mathsf A_v^{9/5}) +\delta\mathsf E_r+C\delta^{-1}\mathsf H^2. \end{aligned} \]

第一行是本版本的主推进：可吸收二阶导数之后，只剩带尺度不变局部动能系数的二次涡量。第二行是显式低阶、过渡与远场代价。把 \(\mathsf F_v\) 换回扩大球耗散时，还要加入上一节列出的截断项。

09 / Value for the main problem

压力不再是当前估计链的主瓶颈，但核心三维困难没有消失

这一步的价值是排除一个真实的技术疑点：R0.69N 的 \(\mu_v\sigma_v^3\) 不是压力机制不可避免的超二次时间代价。把空间插值与可吸收耗散联用后，压力项与 CKN 二次时间量兼容。

它仍不是千禧年问题的解答。首先，适当弱解本身没有先验的 \(L^2_{t,x}\) 二阶导数，完整证明必须从光滑逼近或强解区间建立可统一传递的局部 \(H^1\) 估计。其次，即使压力项完全处理，三维非线性仍含真正的拉伸机制。

价值判断。 这是可用于后续局部高阶估计的压力引理，也是对 R0.69N 时间障碍的严格修正；它把研究资源从压力重新集中到三维涡量拉伸。它不是正则性定理。

11 / Next obstruction

R0.69P 直接审计有符号的三维应变与涡量拉伸

光滑局部 \(H^1\) 计算中的对流项满足尺度不变估计

\[ r^3\int|\nabla u|^3\,dx \le C\sigma^{3/2}\mathcal D^{3/4} \le\varepsilon\mathcal D+C_\varepsilon\sigma^6. \]

若把 Hilbert 插值直接代入，\(\mathcal D\) 的幂反而超过一，不能吸收。因此 R0.69P 不再继续优化压力，而是比较三个可能真正降低拉伸项的结构：应变特征架的有符号代数、涡量方向相干性、以及时空交换子。接受标准是不预设已有 Serrin 或几何正则性判据，却把六次余项降到可由能量层级控制的量；失败则形成明确的无增益命题。
