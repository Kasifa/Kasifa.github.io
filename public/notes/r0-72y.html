01 / Physical linearization

压力右端的 factor two 来自两个不同散度项

\[\partial_tu+V\partial_{x_3}u+u_2V_ye_3+\nabla p=\nu\Delta u,\qquad \nabla\cdot u=0,\]
\[\Delta_Kp=-2iK_zV_yu_2.\]

一份 \(iK_zV_yu_2\) 来自 background transport，另一份来自 shear-gradient term；符号与 \(+\nabla p\) 在左侧的约定一起冻结。

02 / Bloch--Leray row

完整 row label 同时保留水平方向与 residue class

\[j=(K_x,K_z,[r]_R),\quad A_\beta=\partial_x+i\beta,\quad \mathcal L=-A_\beta^2+\mu,\quad \mu=\xi^2+\gamma^2,\]
\[\mathbb P_j=I+\nabla_j\mathcal L^{-1}\operatorname{div}_j,\qquad u_d=-\mathcal Lu-\mathbb P_j(icWu+\Lambda W_xu_2e_3).\]

orthogonal direct sum 是结构恒等式；它不会自动生成 row-uniform bound。

03 / Orr--Sommerfeld--Squire

μ>0 时得到精确三角系统

\[q=\mathcal Lu_2,\qquad \eta=i\gamma u_1-i\xi u_3,\]
\[q_d=(-\mathcal L-icW)q-icW_{xx}\mathcal L^{-1}q,\]
\[\eta_d=(-\mathcal L-icW)\eta+i\xi\Lambda W_x\mathcal L^{-1}q.\]

pressure feedback 与 Squire transfer 的尺度不同；μ=0 不能套用这组逆公式。

04 / Velocity recovery

速度恢复与 kinetic energy identity 均保留方向权重

\[u_1=\frac{i}{\mu}(\xi A_\beta u_2-\gamma\eta),\qquad u_3=\frac{i}{\mu}(\gamma A_\beta u_2+\xi\eta),\]
\[\|u\|_2^2=\|u_2\|_2^2+\mu^{-1}(\|A_\beta u_2\|_2^2+\|\eta\|_2^2).\]
05 / Scalar embedding

R0.72X scalar operator 是完整 row 的严格不变子空间

\[u=g(\gamma,0,-\xi)/\sqrt\mu,\qquad g_d=(A_\beta^2-\mu)g-icWg.\]

scalarA2InvariantEmbedding=CLOSED；scalarA2EqualsCompleteRow=FALSE。一般数据仍会激活 pressure feedback 与 Squire transfer。

06 / Full-row energy

high-gap class 有显式衰减，low-gap class 没有被外推

\[\frac12\frac d{dd}\|u\|^2+\|A_\beta u\|^2+\mu\|u\|^2=-\Lambda\operatorname{Re}\langle W_xu_2,u_3\rangle.\]

若 \(g_j>|\Lambda|M_K/2\)，则 norm exponent 是 \(g_j-|\Lambda|M_K/2\)。这是 damping-dominated full rows，不是完整 low-gap theorem。

07 / Exact lift-up obstruction

zero coupling 仍可产生严格 transient growth

\[u_2(d)=e^{-\xi^2d}v_0,\qquad u_3(d)=-\Lambda d e^{-\xi^2d}W_x(d,x)v_0,\]
\[\frac{\|u(d)\|^2}{\|u(0)\|^2}=e^{-2\xi^2d}\left[1+\frac{\Lambda^2d^2}{8}(e^{-2d}+e^{-8d})\right].\]

ξ=0 时任意非零 Λ 都增长；ξ>0 给 spatially mean-zero 扰动，取足够大的 |Λ| 仍可增长。因此 epsilonOnlyFullRowClosure=FALSE，allPhysicalRowsUniformStrictContraction=FALSE。

08 / Exact causal kernel

几何 block envelope 直接给出 scalar L2 forcing 的 alpha-squared scale

\[\int_0^\infty\!\left(e^{-\mu r}q^{\lfloor r/h\rfloor}\right)^pdr=\frac{1-e^{-p\mu h}}{p\mu(1-q^pe^{-p\mu h})},\qquad h=2T\alpha^2.\]

\(\mu\to0\) 的极限是 \(h/(1-q^p)\)。Young convolution 给 \(L_d^2L_x^2\to L_d^2L_x^2\) 的 \(O(\alpha^2)\) bound。

09 / Negative Sobolev forcing

standard 与 semiclassical negative norm 必须分开

\[\|G\|_{L_d^2L_x^2}\le C_q\alpha\|F\|_{L_d^2H^{-1}_\beta},\]
\[\|G\|_{L_d^2L_x^2}\le C_q\alpha^2\|F\|_{L_d^2\mathcal H^{-1}_{\alpha,\beta}}.\]

两条结论来自 backward-adjoint energy 与 transposition；standardHMinusOneTransferAlpha2=FALSE。

\[\max\{\|G\|_{L_d^\infty L_x^2},\|A_\beta G\|_{L_d^2L_x^2}\}\le C_q'\|F\|_{L_d^2H^{-1}_\beta}.\]

semiclassical 输入的右端另有一个 α。terminal high-frequency pulse 给 order-one endpoint response，所以 HMinusOneEndpointAlphaGain=FALSE。
