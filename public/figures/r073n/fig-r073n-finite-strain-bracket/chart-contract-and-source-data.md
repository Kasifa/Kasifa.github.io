# R0.73N chart contract and source-data note

## Analytical question

Does the exact heat-shear strain have finite total accumulation, is its
fixed-endpoint exponent compatible with the inherited selected-action
interval, and what do those exponent formulas look like across the unbounded
family of marked basepoints?

## Source-data derivation

`source-data.csv` is a row-for-row copy of the validated R0.73N certificate
source data
with the upstream file path and SHA-256 digest appended to every row.  Panel A
uses only `strain_sample`; panel B uses only `cumulative_sample`; panel C uses
only `marked_basepoint_sample`.  The plotter does not solve a PDE or fit any
parameter.

The exact envelope follows from

\[
\frac{1}{2\Lambda}\|\partial_yF_\Lambda(t)\|_\infty
\le e^{-4t}+e^{-16t},
\]

and equality at \(y=\pi/2\).  The first strict endpoint comparison is carried
by \(1-e^{-x}>x-x^2/2\), not by decimal rounding.  The action interval is an
upstream analytic input.

## Claim boundary

The figure is finite and illustrative.  It does not turn the inherited action
interval into a numerical theorem, identify either exponent with the sharp
local flow-map modulus, prove a positive three-dimensional stability radius,
prove arbitrary fixed-background instability, control transverse critical norms,
prove finite-time singularity, or solve the Clay problem.

The source and generated bytes are bound by the package manifest and
`SHA256SUMS`.  Final status additionally requires an explicit source commit
whose source blobs pass byte-for-byte verification.
