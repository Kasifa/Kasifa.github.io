# R0.73R matched-phase shell certificate

This package reproduces the finite Fourier calculations behind the R0.73R
Dirichlet/Rudin--Shapiro comparison.  It uses the normalized Haar measure on
the periodic torus and the vector field

\[
 W_{R,m}(x)=\frac{\sqrt 2}{m}e_3\,\Re\!\left[
 e^{iNx_1}R_m(e^{ix_1})R_m(e^{ix_2})\right],
 \qquad N=8m,\quad m=2^r.
\]

Here `D` denotes the Dirichlet coefficients, all equal to one.  `RS` denotes
the coefficients of the Rudin--Shapiro polynomial generated by

\[
 P_{2m}=P_m+z^mQ_m,\qquad Q_{2m}=P_m-z^mQ_m,
 \qquad P_1=Q_1=1.
\]

For every configured value of `m`, the package checks exactly that:

1. `D` and `RS` have the same `2 m^2` Fourier sites and the same squared
   coefficient magnitude `1/(2 m^2)` at every site;
2. both fields have squared normalized `L2` norm equal to one;
3. the Rudin--Shapiro energy identity
   `|P_m|^2 + |Q_m|^2 = 2m` holds coefficient by coefficient;
4. if `S_R = ||R_m||_6^6`, then

   \[
   \|W_{R,m}\|_6^6=\frac{5S_R^2}{2m^6};
   \]

5. for the Dirichlet polynomial,

   \[
   S_D=\frac{11m^5+5m^3+4m}{20}.
   \]

All `L2` squares and `L6` sixth powers are stored as exact rational strings.
The source table also records the diagnostic quantities

\[
 N^{-1/2}\|W_{R,m}\|_6,
 \qquad
 \alpha_m=N^{1/2}m^{-2/3},
 \qquad
 \alpha_mN^{-1/2}\|W_{R,m}\|_6.
\]

It records the common homogeneous `H1/2` norm before and after multiplying by
`alpha_m` as well.  The theoretical exponent ledger is kept separately from
the finite-grid endpoint slopes: the latter are diagnostics, not asymptotic
proofs.

The first quantity is called `annular_heat_proxy` throughout the package.  It
is not asserted to equal the full heat-flow norm.  The package performs no
time quadrature, no interval arithmetic, and no Navier--Stokes evolution.

## Independent reconstruction

`compute_formula_diagnostic.py` builds the Rudin--Shapiro sequence through the
two-polynomial recursion and obtains sixth moments by two exact polynomial
convolutions.  `independent_validate.py` does not import or execute the
producer.  It generates the signs from the parity of overlapping `11` blocks
in the binary index and reconstructs each sixth moment by direct enumeration
of ordered triples.  It then rebuilds every row and support signature from the
configuration.

Both paths use only the Python standard library, one process, and no GPU.
They are deterministic and do not use DGX.  Progress and peak resident memory
are recorded in `progress.ndjson` and `resource-log.ndjson`.

## Claim boundary

This is a finite formula and error-detection certificate.  It is not:

- an interval-certified heat-flow integration;
- a proof of the Littlewood--Paley/heat-semigroup equivalence;
- a necessary stability criterion;
- evidence that failure of a sufficient smallness test causes blow-up;
- a Navier--Stokes simulation or continuum PDE proof;
- a proof or partial proof of the Clay Millennium problem.

The exact machine-readable boundary is in `config.json` and is copied without
expansion through all certificate layers.

## Reproduction and two-stage seal

Run `command.txt` from the repository root.  The ordinary sealer creates a
`hash-bound-uncommitted` pre-seal.  After the nine source files have been
committed, the parent release can create a commit-bound seal with

```text
seal_package.py --source-commit <full-lowercase-40-hex>
```

The sealer never substitutes `HEAD` for an explicit commit.  Both
`--verify-only` modes are fail-closed and perform no writes.
