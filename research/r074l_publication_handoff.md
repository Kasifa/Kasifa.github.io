packet Jensen majorant frozen in R0.74L (F.5), the core commit proves

\[
 \boxed{
 \sup_{\tau\in I_{R_j}}\mathscr B_j(\tau)
 \le C L_jR_j^5.}
\]

The proof keeps the normalized periodic bridge, all windings, the true
shear, and the collar geometry.  It first integrates the endpoint-dependent
bridge family into one common forward Brownian law, then separates rare
transition-approach paths from a positive short-clock tube.  On that tube,
the clock support has length `O(L_j R_j)`, physical duration
`O(L_j R_j^3)`, and a fixed thickened-slice BV cost `O(L_j R_j)`.

 |F_j|^2\le2(|F_j^+|^2+|F_j^-|^2),

\]

No positive/negative packet cancellation is claimed.  This closes only the
main target collar.  The nearest inward collar still requires a different
quantitative positive-shear expulsion estimate, so the full signed R0.74K
condition (4.3) and the matching upper bounds remain **OPEN**.
