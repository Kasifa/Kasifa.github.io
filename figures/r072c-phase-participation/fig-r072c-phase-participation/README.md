# R0.72C phase-participation figure

This package archives the formal double-column figure for R0.72C. It is built
only after the producer and independent R0.72C certificates pass.

Expected release files:

- data.csv
- results.json
- figure.pdf
- figure.svg
- figure.png at 600 dpi
- qa-original.png
- qa-grayscale.png
- qa-pdf.png
- manifest.json
- validation.json
- qa-report.md
- progress.ndjson
- resource-log.ndjson
- SHA256SUMS

The visual claim is limited to exact algebraic prefactors and sufficient
upper regions. It does not certify a lower bound for the actual root ledger.
