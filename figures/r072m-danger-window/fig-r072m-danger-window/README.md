# R0.72M formal figure package

This package records the exact scalar danger window and the one-carrier
full-lattice phase-mixing benchmark proved in
`research/r072m_report-source.md`.

Panels A and B are analytic formula samples. Panel C compares two independent
finite evaluations of the zero-diffusion reference cubic with the proved
constant `16/pi^2`. Panel D shows two independently converged dissipative
finite-chain diagnostics. Panel D is not a theorem and is not used to prove a
Navier--Stokes estimate.

The archival masters are `figure.pdf`, `figure.svg`, and a 600 dpi
`figure.png`, all at 177.8 x 124.0 mm. `data.csv` preserves each plotted datum
and its source pointer. The public copies under `public/assets/r072m/` are
required to be byte-identical to the masters.

`manifest.json`, `SHA256SUMS`, `validation.json`, and the QA surfaces complete
the formal archive after an explicit visual inspection and a clean two-commit
certificate seal.
