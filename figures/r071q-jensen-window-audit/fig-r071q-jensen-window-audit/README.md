# Figure R0.71Q -- Jensen window audit

This formal figure package supports the finite R0.71Q method audit.  It
contains exact and independent certificates, the plotting table, PDF/SVG/600
dpi PNG outputs, QA previews, provenance metadata, and hashes.

Panels B--D are analytic counterfamilies, not Navier--Stokes trajectories.
Panel A visualizes a classical strong-solution complex-time theorem and an
exact conservative disk extraction.  No uniform NSE zero count,
continuation, singularity, or global-regularity claim is made.

Run the commands in `command.txt` from this directory.
