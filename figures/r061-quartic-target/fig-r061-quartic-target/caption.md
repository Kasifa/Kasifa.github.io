# Figure R0.61-1 — Finite quartic target scan in the invariant shear chain

**English.** For the R0.59 tensor Rudin--Shapiro packet, the complete quartic
target coefficient satisfies
\(A^4\widehat G_4/(A^2\widehat G_2)=-(\varepsilon^2/L^2)R_{L,M,m}\).
(a) Complete target profiles for four representative \((L,M)\) families.
All 416 displayed values are positive, so the observed quartic correction is
opposite in phase to the coherent quadratic target.  The logarithmic vertical
axis exposes both the small low-target values and the edge-scale peaks.
(b) Edge-target values over the archived dyadic scaling families.  The largest
observed value is \(1.3286562612067\times10^{-3}\) at
\((L,M,m)=(4,64,64)\); a separate 60-decimal evaluation agrees with the
long-double scan to relative discrepancy below \(5.6\times10^{-15}\).
Across the full certificate, 461 distinct triples and 7,494,536,238 ordered
quartic paths were evaluated.  Positivity, the displayed maximum, and absence
of growth in \(M\) are finite numerical evidence only.  A uniform bound still
requires an all-index weighted four-point Rudin--Shapiro correlation theorem.
