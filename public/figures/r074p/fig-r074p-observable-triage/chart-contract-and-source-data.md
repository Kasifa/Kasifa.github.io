# Chart contract and source data

## Analytical question

The figure compares the exact asymptotic discrimination supplied by the
R0.74P proofs. It asks which candidates under-detect, match at the target
shell, or over-penalize the R0.74O concentration scale \(T_*\).

## Source

All rows are deterministic evaluations of formulas proved in the R0.74P
main note:

- Panel A uses Theorem 4.2:
  \(\log_{10}(\mathcal C_\sigma/T_*)\le
  \log_{10}C-\min\{\sigma,1\}\log_{10}K_*\).
  The CSV and plot record only the decay term
  \(-\min\{\sigma,1\}\log_{10}K_*\).  The unknown additive constant
  \(\log_{10}C\) is deliberately suppressed, so the curves encode slopes
  and asymptotic rates, not absolute vertical values.
- Panel B uses Lemma 4.1 and equations (4.5)--(4.6), normalized by
  \(a=2m/3\). Since
  \((c_\Gamma/2)/a=(4/3969)/(43/635040)=640/43\), the strong target
  lower bound has normalized rate \(640/43\).

The source CSV is generated by the plotting program from the frozen config
and exact Fraction inputs. Panel A contains 49 points for each of three
distinct rate envelopes. Its `log10_decay_term` column is not named or
interpreted as the full logarithmic upper bound. Panel B contains five exact
ledger rows.

## Honest-reading boundary

Panel A plots the proved decay-rate term with an unspecified additive
intercept suppressed, not an absolute upper-bound curve or observed values.
Panel B states only
the matched target component \(v_j\asymp T_*\), not a two-sided law for the
full square function. The figure contains no stochastic or numerical
Navier--Stokes trajectory.
