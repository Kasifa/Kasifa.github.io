01 / Formal statement

我们究竟要证明什么

研究的第一条纪律是固定方程、定义域、初值类别与解的概念；任何改变这些条件的结果都只能算相关研究。

三维不可压缩 Navier–Stokes 方程为

\[ \partial_tu+(u\cdot\nabla)u=-\nabla p+\nu\Delta u,\qquad \nabla\cdot u=0,\qquad u(0,x)=u_0(x), \] \(u:\Omega\times[0,\infty)\to\mathbb R^3\) 是速度，\(p\) 是压力，\(\nu>0\) 是黏性系数。

Clay 正式问题允许在全空间 \(\mathbb R^3\) 或周期空间 \(\mathbb T^3=\mathbb R^3/\mathbb Z^3\) 上作答。正面答案需要证明： 对任意满足规定衰减或周期条件的光滑无散初值，存在全局光滑解。负面答案则需要按正式问题允许的条件构造有限时破裂。

本站的首选精确目标：Clay 命题 B

在 \(\mathbb T^3\) 上，对任意光滑、周期、无散且平均为零的初值 \(u_0\)，证明无外力方程存在唯一全局光滑解。 周期情形避免了无穷远衰减的附加技术问题，也天然适合 Fourier 分析；它本身就是完整的千禧年问题选项，而非弱化版。

尺度与临界性

在 \(\mathbb R^3\) 上，方程具有缩放

\[ u_\lambda(x,t)=\lambda u(\lambda x,\lambda^2t),\qquad p_\lambda(x,t)=\lambda^2p(\lambda x,\lambda^2t). \]

若一个范数在该缩放下不变，就称为尺度临界。典型临界量包括 \(L^3_x\)、\(\dot H^{1/2}_x\)、\(\dot B^{-1+3/p}_{p,q}\) 和 \(L^q_tL^p_x\)（满足 \(2/q+3/p=1\)）。基本能量 \(\|u\|_{L^2}\) 在高频缩放下变小，因而对三维正则性是超临界控制： 它允许能量在越来越小的空间尺度上集中。

02 / State of knowledge

研究综述：我们已经站在哪里

下列结果构成所有可信攻关方案必须穿过的边界。它们不是零散技巧，而是一张“什么已被控制、什么仍失控”的地图。

Global · weak

全局弱解存在

Leray–Hopf 理论对有限能量初值给出全局弱解，并满足能量不等式。 未解决的是一般无外力情形下的光滑性，以及弱解层面的适当唯一性。

Local · strong

光滑解局部存在

足够光滑的初值产生唯一局部强解；如果最大存在时间有限，那么某个临界或超临界正则量必须发散。 问题被压缩为：排除有限时发散。

Global · small critical data

临界空间小数据全局

Fujita–Kato、Kato、Koch–Tataru 等理论在 \(\dot H^{1/2}\)、\(L^3\)、\(BMO^{-1}\) 等临界框架中建立小数据全局适定性。 缺失的是任意大小临界数据的先验控制。

Global · structured large data

部分结构化大数据全局

近二维、缓慢变化、特定对称或稳定背景附近，可以构造范数任意大的全局光滑数据。 这证明“大”本身不是唯一障碍；危险在于尺度、方向和相互作用结构。

能量与涡量：一个成立、一个不闭合

对光滑无散解，基本能量恒等式为

\[ \frac12\|u(t)\|_2^2+ \nu\int_0^t\|\nabla u(s)\|_2^2\,ds =\frac12\|u_0\|_2^2. \]

令 \(\omega=\nabla\times u\)，涡量满足

\[ \partial_t\omega+(u\cdot\nabla)\omega =(\omega\cdot\nabla)u+\nu\Delta\omega. \]

二维中涡量拉伸项消失；三维中 \((\omega\cdot\nabla)u=S\omega\) 可以放大涡量，其中 \(S=(\nabla u+\nabla u^\mathsf T)/2\) 是应变张量。相应的 enstrophy 恒等式含有无定号项

\[ \frac12\frac{d}{dt}\|\omega\|_2^2+ \nu\|\nabla\omega\|_2^2 =\int_{\Omega}(S\omega)\cdot\omega\,dx. \]

部分正则性与条件正则性

理论边界严格结论仍然缺失状态
CKN 部分正则性 适当弱解的奇异集一维抛物 Hausdorff 测度为零。 不能证明奇异集为空。 已验证
Ladyzhenskaya–Prodi–Serrin 若 \(u\in L^q_tL^p_x\)，\(2/q+3/p\le1\)、\(p>3\)，则正则且唯一。 能量不等式不能推出该条件。 已验证
端点 \(L^\infty_tL^3_x\) 临界 \(L^3\) 范数有界可排除有限时奇点。 不能从初始能量推出全程 \(L^3\) 有界。 已验证
涡量方向准则 高涡量区的方向相干性可削弱 vortex stretching 并保证正则。 一般解是否自动获得这种相干性未知。 条件结果
临界元方法 若某些临界空间中存在爆破解，可抽取最小爆破轮廓。 缺少排除该临界元的刚性定理。 开放关口

弱解非唯一性改变了什么

Buckmaster–Vicol 证明有限动能弱解在较宽弱解类中可以不唯一； Albritton–Brué–Colombo 进一步证明某个特制外力下的 Leray 解不唯一。 这些结果说明“分布意义满足方程 + 有限能量”远不足以恢复经典动力学，但它们没有直接给出由光滑初值产生的有限时奇点。

2025 年提交、2026 年修订的一篇预印本由 Hou–Wang–Yang 主张给出 无外力三维 NS 的 Leray–Hopf 非唯一性的严格计算机辅助证明。 这是极重要的前沿信号，但截至本综述日期仍应标为预印本主张，不能等同于已经过同行评议和独立复核的定理； 即使该结论被确认，它讨论的也是粗糙初值与弱解唯一性，不自动解决 Clay 要求的光滑初值全局光滑性。

逻辑隔离

“弱解不唯一”“存在粗糙自相似解”“数值计算出现高涡量增长”都不等价于 “某个光滑初值的经典解有限时爆破”。任何公开结论必须写出初值正则性、能量不等式、适当性、外力和解类。

03 / Research frontier

从经典基石到当前边界

这条时间线只选取会改变我们攻关策略的节点；“改进一个条件正则性指数”与“跨越逻辑关口”并不等价。

1934

Leray：全局有限能量弱解

建立现代弱解框架，并明确留下规则性与可能奇异性问题。

1960s–1980s

局部强解、临界小数据与 Serrin 准则

半群方法和尺度临界空间逐渐形成现代适定性框架。

1982

Caffarelli–Kohn–Nirenberg

将适当弱解可能的奇异集合压缩到极小，但未能证明其为空。

1993

Constantin–Fefferman 涡量几何

证明 vortex stretching 具有可被方向相干性削弱的精细几何结构。

2001–2003

\(BMO^{-1}\) 小数据与 \(L^\infty L^3\) 端点

Koch–Tataru 扩张小数据临界理论；Escauriaza–Seregin–Šverák 完成关键端点正则性。

2011–2013

结构化大数据与临界元

任意大但特殊结构的数据可全局；浓缩紧致性将潜在爆破压缩为最小临界对象。

2016

Tao 的 averaged NS 爆破

证明能量恒等式与通用调和分析估计不足以解决问题，必须利用原始非线性核的更细结构。

2019–2024

定量临界正则性、凸积分与部分正则性改进

临界范数爆破下界被定量化，弱解非唯一性边界推进，CKN 理论获得对数级改进。

2025–2026

计算机辅助弱非唯一性预印本

无外力 Leray–Hopf 非唯一性被一篇计算机辅助预印本主张实现；需要同行评议、代码复核与独立再验证。

04 / Why it resists

真正的困难不是“非线性很复杂”

困难可以精确定位为：现有全局受控量位于超临界尺度，而所有已知正则性判据要求临界或更强的控制。

Barrier 01

能量超临界

\(L^2\) 能量可以在越来越高的频率上以越来越小的代价存在，因此总能量有界不排除高频集中。

Barrier 02

涡量拉伸无定号

\(\int(S\omega)\cdot\omega\) 既可能衰减也可能增长；粗略取绝对值会丢掉可能决定正则性的几何抵消。

Barrier 03

压力非局部

\(-\Delta p=\partial_i\partial_j(u_i u_j)\)。局部速度结构会通过 Riesz 变换影响远处，局部化估计产生压力尾项。

Barrier 04

临界尺度紧致性缺失

平移、缩放与频率漂移使极限过程丢失紧致性；潜在奇点可以沿嵌套尺度逃逸。

Tao 障碍的研究含义

任何只使用 \(\langle B(u,u),u\rangle=0\)、双线性算子阶数和一般 Calderón–Zygmund 估计的正面证明，都应首先与 averaged Navier–Stokes 的有限时爆破例子比较。 若同一论证也“证明” averaged 方程全局正则，那么论证必然在某处失效。

05 / Chosen strategy

主攻路线：寻找原始非线性核的临界耗散结构

我们暂不假定答案必为全局正则，但第一主线选择正面路线；所有候选不等式必须通过尺度、精确 Fourier 三波相互作用和已知反例模型三重审计。

在 \(\mathbb T^3\) 上设 \(P_j\) 为 Littlewood–Paley 频率投影，并定义临界频率包络

\[ a_j(t)=2^{j/2}\|P_j u(t)\|_2,\qquad \|u(t)\|_{\dot H^{1/2}}^2\simeq\sum_j a_j(t)^2. \]

每个频率壳满足形式上的局部能量关系

\[ \frac12\frac{d}{dt}\|P_j u\|_2^2 \nu\|\nabla P_j u\|_2^2 =-\int_{\mathbb T^3}P_j(u\cdot\nabla u)\cdot P_j u\,dx. \]

通用 paraproduct 估计不足以闭合临界能量。我们要调查的是：无散条件、Leray 投影、 三个波数的几何关系和实值共轭对称性，是否使危险的 high–high、high–low 相互作用获得 一个可求和的“缺陷因子”。该因子若存在，必须是原始 NS 特有的，不能只依赖抽象能量抵消。

两个可能的最终出口

路线需要跨越的决定性关口成功时的含义
正面：全局光滑 从能量和方程结构推出一个全局有界的临界量，或排除所有最小爆破临界元。 完成 Clay A 或 B。
负面：有限时破裂 构造满足精确 NS 相互作用、光滑初值与正式外力条件的级联，并严密验证奇点。 完成 Clay C 或 D。

若 Fourier 审计发现原始核允许稳定的单向能量级联而无普适耗散缺陷，我们将把该结构记录为负面路线候选； 在此之前，不凭数值外观选择“爆破”叙事。

06 / Research program

详细研究计划：逐项过关，而不是宣称直攻终点

每一阶段都有可交付成果、通过标准和停止条件。前一关未通过，不把后续推导包装成证明。

固定目标、记号与证明审计协议

正式选择 \(\mathbb T^3\) 无外力正面命题；建立唯一的定义、Fourier 约定和解类词典。

交付
《基础约定 v1》：方程、Leray 投影、函数空间、缩放表、引用规范。
通过标准
所有后续命题均可明确回指假设，不混用 \(\mathbb R^3\)、通道与周期域。
停止条件
若一个结论依赖额外对称、额外耗散或外力，立即降级为“相关子问题”。

独立重建已知基线

完整复现局部强解、能量估计、弱–强唯一性、Serrin 准则和一个 \(\varepsilon\)-正则性命题。

交付
可逐行检查的证明笔记；每条估计标注尺度、常数依赖和密度论证。
通过标准
不以“标准可得”跳过会在临界端点失效的步骤。
研究价值
建立我们自己的错误检测基线，并定位每个已知证明损失了什么。

建立非线性障碍图谱

对精确 Fourier 三线性形式进行 dyadic 分解：low–high、high–low、high–high 与近共振三波。

交付
相互作用核公式、对称性清单、最坏三波族、候选不等式反例库。
通过标准
每个候选估计同时通过 NS 缩放、单三波测试和多壳级联测试。
停止条件
若估计对 Tao averaged 非线性同样成立，则不能作为决定性新结构。

寻找临界“耗散缺陷”或几何枯竭因子

联合频率包络、涡量方向和应变本征结构，尝试提取危险能量通量中的角度或频率小因子。

目标命题
得到严格弱于已知 Serrin 假设、但足以阻止持续向高频迁移的条件性定理。
通过标准
条件必须由可演化量表达，且不能把待证临界范数有界偷偷写入假设。
失败也发布
显式 Fourier 反例、常数爆炸或端点失败均进入“否定结果”档案。

从条件性定理推进到临界元刚性

若存在有限时爆破，利用 profile decomposition 抽取最小临界解；证明它必须具有步骤 4 排除的结构。

交付
紧致模对称性、局部能量集中下界、backward uniqueness 所需的定量假设。
决定性关口
证明最小临界元不存在；或反向发现一个与全部刚性条件相容的候选。
风险
紧致性本身不会产生矛盾，真正的新内容必须出现在 rigidity。

闭合全局先验估计或转入严格爆破构造

正面路线力求获得任意光滑初值的临界范数有限性；负面路线必须从光滑数据严格构造奇点。

正面终点
\(\sup_{t\le T}\|u(t)\|_{L^3}\) 或等价临界控制对每个有限 \(T\) 有界。
负面终点
满足 Clay 正式条件的有限时无光滑解构造，不以修正模型代替。
审计
独立重证关键引理，公布计算代码、区间误差与机器可复核证书。

外部验证与 Clay 标准

先寻求领域专家逐条审阅，再投稿同行评议；处理所有公开反例与勘误。

公开材料
主论文、完整附录、依赖图、代码、失败尝试与版本差异。
完成标准
依照 Clay 规则，需在合格出版物发表并经过规定的接受与等待过程。
原则
网页不是认证机制；它是透明研究记录与可复现材料入口。
07 / Start here

第一项任务已经明确

不从“提出一个宏大新泛函”开始，而先建立能迅速杀死错误想法的精确临界障碍基线。

Research packet R0.1

周期三维 NS 的临界能量与 Fourier 三波结构

下一份研究笔记应逐项完成：

  1. 从压力形式严格导出 Leray 投影形式与 mild/Duhamel 公式。
  2. 列出 \(L^p\)、\(\dot H^s\)、Besov 与混合时空范数的精确缩放。
  3. 推导 \(L^2\)、enstrophy 与 \(\dot H^{1/2}\) 能量演化式，标出唯一不能闭合的三线性项。
  4. 写出 Fourier 系数方程 \[ \partial_t\widehat u(k)+\nu|k|^2\widehat u(k) =-i\!\!\sum_{p+q=k}\!(q\cdot\widehat u(p))\,\mathbb P_k\widehat u(q), \] 并核对实值、无散与三波能量交换对称性。
  5. 构造最小 Fourier 三波和多壳样例，检验所有拟议临界不等式。

完成判据：形成一份可公开的、逐行可复核的 HTML/PDF 笔记，并得到“哪些类型的普适估计不可能成立”的清单。

08 / Open publication

用个人网页发布：GitHub Pages 是合适的第一选择

研究站点应当像实验记录本：每个版本可追踪、每个结论有状态、每个计算可复现，而不只是展示最终论文。

推荐结构

页面/目录内容更新规则
/问题状态、研究地图、当前任务与最近更新。每个里程碑更新。
/review本综述及带版本的参考文献。季度或重要结果出现时。
/notes编号研究笔记 R0.1、R0.2……只增补，不无痕覆盖。
/claims定理、复现、猜想、数值证据、已否定命题。状态变化必须写理由。
/code符号计算、区间算法、测试与复现实验。与对应笔记使用同一版本号。
/changelog勘误、外部评论与逐项回应。任何实质修改均记录。

最简单的 GitHub Pages 发布方式

  1. 注册或使用现有 GitHub 账号。
  2. 创建名为 你的用户名.github.io 的公开仓库；这是个人主页地址。
  3. 把本项目中的 research-review.html 作为仓库根目录的 index.html。
  4. 在仓库 Settings → Pages 中选择从分支发布，或选择 GitHub Actions。
  5. 推送后访问 https://你的用户名.github.io；首次发布可能需要数分钟。

如果主页还要展示个人简介、论文和其他项目，可用 你的用户名.github.io 做总主页， 再把本研究放在单独仓库 navier-stokes-research，地址会是 你的用户名.github.io/navier-stokes-research/。

本站已按“单页静态 HTML”设计

无数据库、无登录、无服务器依赖，适合 GitHub Pages；MathJax 用于公式显示。 发布前只需补充作者姓名、联系方式、许可协议，并检查是否有不应公开的本地文件。 后续若研究日志增多，可升级为 Jekyll、Quarto、Astro 或 React 静态站点。

可信度设计

  • 已验证：同行评议结果或我们已完整复现的命题。
  • 预印本：作者公开主张，但尚需同行评议或独立复核。
