# Figure R0.73L — adiabatic tracking diagnostic

This is the formal static figure package for the finite R0.73L dynamics.
`source-data.csv` is derived from the sealed primary and independent JSON
outputs.  PDF and SVG are vector exports; PNG is rendered at 600 dpi.  The QA
surfaces include final-size, grayscale, and PDF-raster views.

The figure is evidence for numerical reproducibility only.  It does not
certify the continuum adiabatic theorem, an explicit epsilon threshold, a
nonlinear instability, or the Clay problem.
