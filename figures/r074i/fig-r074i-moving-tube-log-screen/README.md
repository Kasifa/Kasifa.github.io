# R0.74I moving-tube/log-screen figure package

This directory is the deterministic formal figure package for R0.74I.
Panel A records the proved moving-tube implication chain. Panel B records the
exact affine exponent screen `y(gamma)=1-2 gamma` and keeps rejection,
endpoint openness, and non-rejection visibly separate.

Run the commands in `command.txt` with the bundled Python and Poppler tools.
Rendering is refused unless the producer and certificate hashes match and the
producer reproduces the frozen 36/36 JSON byte for byte. The validator checks
the source-data reconstruction, vector PDF, 600-dpi raster, embedded fonts,
declared palette, non-color distinctions, layout proxies, full file inventory,
and all checksums. This is an exact diagram, not DNS, simulation, or a Clay
result.
